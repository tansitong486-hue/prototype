需求说明 v2.9 需求文档

页面级：让实施在机房配置上线寻优前，看清每台空调能否被仿真寻优动作、为什么不能，以及机房拓扑是否完整。

  • 覆盖场景：新建保存后首次校验；去物模型补属性 / 补绑点 / 改关系后重新校验；编辑模型后结果过期再校验。
  • 本期不覆盖：不在本页修改任何属性、绑点或关系（只读 + 跳转去维护 / 去配置）；不做定时自动校验与告警推送；不校验仿真精度（精度看「仿真验证」页）。
  • 与寻优的关系：寻优每轮按同一规则表逐台判定，本页结果不是寻优的开关；未校验的模型照常寻优（产品推断）。
提示

1、机房配置校验按每台空调的对象类型，检查仿真寻优所需的属性、关键测点绑定与测点数据合理性，并检查机房供冷 / 换热 / 回风关系是否完整。

2、ERROR 的空调会移出可动作集（寻优时保持当前控制不动作），其余空调照常寻优；拓扑不完整、IT 功率未绑或投入传感器温度未绑时机房寻优跳过。温度未绑：机房不能寻优；不需要检查的测点请投出。WARN 请核对。

数据逻辑 v2.9 需求文档

关联模块：校验明细 — 七类校验

前五类：① 调节方式与转速反馈一致；② 压缩机数量与组件实例数一致；③ 控制型对应主温度设定写点；④ 冷冻水型设计点完整；⑤ 供冷、换热、通道与回风拓扑完整。另查必填静态属性，不另计一类。新增⑥关键测点绑定、⑦测点数据合理性，仅查投入空调、投入传感器与空调设备组。

每次读取当前属性、绑点、组件、投入状态、关系和近 7 天 5 分钟数据。① 无转速或频率证据则无法校验；定频但 10%～90% 中间值占比 >20% 记 WARN。每台每类最多一行 PASS 汇总，「只看问题项」隐藏 PASS。

数据逻辑 v2.9 需求文档

关联模块：数量、控制型与设计点

② 数量与组件数不一致记 WARN / CONFIG_SUSPECT(COMP_NUM)，按实例数计算。

③ 回风温控需绑 4_25_0，送风温控需绑 4_27_0；控制型或写点缺失记 ERROR / INPUT_MISSING。

④ 冷冻水型 designWaterInTemp、designAirInTemp、designAirOutTemp 缺一记 ERROR / INPUT_MISSING；设计出风≥进风或反解不收敛记 WARN / CONFIG_SUSPECT(DESIGN_POINT)。缺设计进出水温差、进风湿度分别按 5℃、50%RH。其他必填缺失记 ERROR。

数据逻辑 v2.9 需求文档

关联模块：原有校验 — 拓扑完整性

⑤ 每台参与寻优空调至少有 1 条供冷冷点边，每个投入冷点至少有 1 条入边。每个投入且有安全边界的热点至少有 1 条换热入边；每条投入通道至少有 1 个热点，无封闭机房不查这两项。

封闭热通道机房里每台参与寻优空调，或摆放位置为行间 / 列间的空调，须有来自投入热点的回风入边；房间级可不配，无封闭不查。上述缺失均记 ERROR / TOPOLOGY_INCOMPLETE，机房本轮 SKIPPED，回风关系逐台一条。

数据逻辑 v2.9 需求文档

关联模块：关键测点绑定 — 投入空调必需测点

运行状态 2_167_0、回风温度 1_21_0、送风温度 1_22_0、有功功率 1_627_0 必需；风冷型另需室外干球 1_2987_0。未绑记 ERROR / INPUT_MISSING，该空调移出可动作集，点「去绑点」。主温度设定写点仍由③检查，不重复。

已绑但近 7 天有效样本不足 50%，记 WARN / INPUT_MISSING「长期无值」。投出空调只查额定风量与供冷关系，不查新增两类。

数据逻辑 v2.9 需求文档

关联模块：关键测点绑定 — 投入空调可选测点

未绑均记 WARN / INPUT_MISSING。风机转速 1_3152_0 缺失，风量按风机转速上限设定估算；上限写点 4_90_0 缺失，该空调风机上限不调整。

冷冻水型：水阀最大开度写点 3_2001_0 缺失则水阀不调整；进水温度 1_27_0 缺失取冷站供水温度 +0.5℃；水阀开度 1_4_0 缺失则无容量真值。

风冷型逐组件查转速 / 状态 1_1052_10#j / 2_186_10#j。无容量真值时，送风温度、功率模型标低置信。

数据逻辑 v2.9 需求文档

关联模块：关键测点绑定 — 传感器与设备组

投入温湿度传感器：温度 1_1_0 未绑记 ERROR / INPUT_MISSING，机房结论为阻断、本轮 SKIPPED。温度未绑：机房不能寻优；不需要检查的测点请投出。湿度 1_960_0 未绑记 WARN / INPUT_MISSING，「该点不做湿度检查」。

空调设备组 IT 功率 1_105_0 未绑记 ERROR / INPUT_MISSING，「机房不能寻优」，横幅与机房结论显示阻断、本轮 SKIPPED。以上问题进明细及 ERROR / WARN 统计，不进入空调总览。

数据逻辑 v2.9 需求文档

关联模块：测点数据合理性 — 窗口、越界、写死与跳变

只查已绑且近 7 天有数据的测点，用 5 分钟数据；不足 24 小时记 INFO「无法校验」。异常记 WARN / CONFIG_SUSPECT(POINT_DATA)，操作「核对测点」。

越界：超出物模型量程或物理范围，温度 0～60℃、湿度 0～100%RH、转速 / 开度 0～100%、功率≥0；占比>5%提示。

写死：连续 12 小时极差<ε且邻点同期有变化；温度 ε=0.02℃、功率 0.1 kW、转速 / 开度 0.1%。跳变：相邻 5 分钟温差>5℃或功率差>额定功率50%，排除启停。近7天出现即提示并写次数。

数据逻辑 v2.9 需求文档

关联模块：测点数据合理性 — 物理关系与证据

命中占比>5%提示：运行时送风温度≥回风温度，疑似送回风绑反；热点温度<所连冷点温度，疑似冷 / 热通道传感器装反或分组错；运行时功率≤待机功率、停机时功率>1 kW；风机转速>风机转速上限设定+5%。

明细写近7天命中占比、命中数 / 有效样本数、最近时间；写死写持续时长与次数，跳变写次数。每台空调每类最多一行「已校验」，汇总必需测点绑定数或无异常测点数，不逐测点出 PASS。

交互说明 v2.9 产品推断

关联模块：校验明细 — 筛选与处置

级别、实例、关键字及「只看问题项」即时筛选。实例含各空调、温湿度传感器、空调设备组和机房拓扑；总览「查看明细」定位到该空调。

「去修改」回编辑步骤 1 并定位属性；控制型不符可改控制型或去绑点；「去配置」回步骤 2 定位关系；「去绑点」到设备管理的该实例测点绑定；「核对测点」查看该实例测点曲线与绑定。均带回跳，保存返回后自动重新校验。原型以提示演示。

「重新校验」重跑全部规则，刷新两张表与统计；执行期间禁用。面包屑与标题左箭头返回列表。

边界与异常 v2.9 需求文档

关联模块：校验明细 — 边界与异常

控制型或对应写点缺失记 ERROR / INPUT_MISSING。空调缺必需输入先移出可动作集；运行中且物理量无法估计时寻优整轮跳过，本页不替代每轮运行态判定。

全部投出或未关联空调，可动作集为空，机房阻断。投出空调只查额定风量和供冷关系，缺失仅 WARN、仿真不计该台送风。

封闭热通道机房的投入空调、行间 / 列间空调须配回风关系；无封闭机房不查。摆放位置读 placement_position，底座式或未填按房间级；封闭方式读空调组 aisleSealedMode。缺 IT 功率或投入传感器温度未绑均独立阻断机房。
