变更概述（2026-08-26 补充）：能源计量与供电关系引入拓扑版本管理（按能源类型各一条版本时间线，详见《能源拓扑配置》页批注），本页口径同步调整：① 指标出数按查询时间段所属生效版本的拓扑解释，跨版本边界分段拼接，历史区间不再因新改造重算——取代 2026-07-31 口径中「改绑后全部保留期实时历史自动重算并整体替换」的说法；重算仅发生在某版本自身内容变化时，范围限于该版本已生效区间。② 对象在某版本区间内无计量关系时，该区间显示「无计量关系」而非 0。③ 本页「能效配置」Tab 的单对象能源拓扑弹窗仅操作各能源最新版本，不提供版本切换；查看历史版本、新建版本请到《能源拓扑配置》。

变更概述（2026-07-31 补充）：实时指标调整为沿用数据工厂默认调度计算后写入时序存储，支持当前值与历史曲线；列表增加样本状态，演示正常、待配置、重算中和重算失败保留旧值。计量拓扑改绑或方向调整后，受影响对象及递归上级对象的全部保留期实时历史自动重算，成功后原子替换（2026-08-26 起按拓扑版本口径收敛，见上一条）。删除已取消的「总电流」指标及本体、组件演示数据。单对象能源拓扑的关系类型改为只读：支持供电的列头柜 / 支路新增即同时创建能耗计量与供电两条独立关系，页面合并为一行双标签；方向只改计量关系，删除成员一次移除两条关系。

变更概述（2026-07-30 补充）：节点详情的「测点列表」与「内置指标」统一按「本体 / 组件」折叠分组；平台仍不提供组件独立详情页，组件指标在所属设备页面展示，但曲线、计算口径和下钻均使用组件自身实例 ID。默认演示对象调整为「101空调-1」，直接展示本体与风机组件的指标差异。「能效配置」Tab 的单对象入口同步为「能源拓扑配置」，同时维护能耗计量与供电关系；今日试算和用能定额仍只读取能耗计量关系，跨对象批量作业与 Excel 全局导入导出继续在独立页完成。

变更概述（2026-07-27）：页面名称统一为「能效视图」；节点详情新增「内置指标」Tab。指标按取值方式分为实时指标与查询指标：实时指标直接平铺当前对象已配置能源的瞬时值及能效值；查询指标由用户发起查询时按自身声明的查询参数即时计算。本期所有查询指标仅要求起止时间，后续可按指标定义扩展其他查询参数；能源类型、计费时段均固化进指标名称。列表在指标名称后展示「业务分类」（本期均为「能效」），并展示简明计算口径，点击后以只读弹窗查看计算拓扑、实际引用的对象属性 / 测点 ID、节点结果、异常节点和最终计算过程。

  • 供电关系：用于表达实际供电路径，不设置计量方向；支持供电的支路新增时自动与能耗计量关系同时创建，页面合并显示两个只读标签，底层两条记录仍独立维护。
  • 拓扑版本口径（2026-08-26）：两类关系按能源类型做版本管理，版本时间线、新建版本与历史版本查看统一在《能源拓扑配置》；本页指标出数按查询时间段所属版本的拓扑解释，某版本区间内无计量关系时显示「无计量关系」而非 0；本页单对象弹窗仅操作各能源最新版本。

关联模块：内置指标 — 实施核数与计算链路排查

  • 本体 / 组件分组：复用测点列表结构，在当前设备实例详情中按本体和所属组件分组。组件不新增详情入口；每条组件指标仍以组件实例 ID 取值、打开曲线和下钻，同名指标通过分组区分。
  • 实时指标：不提供能源类型筛选。默认「仅有值」：只展示本体及组件已有成功样本的能源瞬时值；可切换「全部」查看适用指标全集，算不出的显示「待配置」。C1 与 PUE / CLF / PLF / OLF / WUE 实时值沿用数据工厂默认调度计算后写入时序存储，支持当前值与历史曲线；PUE / CLF / PLF / OLF / WUE 仅在适用物模型实例上出现。
  • 实时指标编辑：每行提供「编辑」，点击后在当前右侧区域进入与现网测点一致的编辑详情，保留基础设置、高级设置和告警配置；取消或返回恢复指标列表。内置定义只读，别名、输入提示和告警配置可维护。指标由指标工厂计算，因此编辑页不提供赋值设置。
  • 查询指标：每一行均有独立的「查询参数」列，参数由指标定义声明；本期每行提供开始日期和结束日期，后续可按指标扩展其他参数。顶部只提供一个统一「查询」按钮，点击后按各行参数分别查询并刷新结果；首次进入查询指标时按默认参数自动查询一次。能源类型、计费时段固化进指标名称；本期查询指标不提供曲线入口。
  • 数据时间边界：实时指标是已写入时序存储的样本，继续展示状态与数据时间；查询指标是按参数即时计算的派生结果，不属于事实数据，不展示「数据时间」，对应列改为「查询参数」。
  • 样本状态：实时指标正常样本展示「正常」；依赖不完整显示「待配置」且不写 0；拓扑变更期间继续展示旧版本并标记「重算中」；分片失败保留最近成功值并标记「重算失败」。数据时间始终是当前展示的实时样本时间，避免旧值被误认作最新正常值。
  • 计算排查：点击绿色计算口径打开只读预览。组件行以组件实例为计算根节点；组件出现在父级页面不代表自动计入本体，只有显式配置计量关系后才参与本体归集。
  • 业务分类：列表展示「业务分类」列，筛选区提供业务分类选择器（默认「全部」）。本期指标（实时 / 查询两种取值方式下的能耗、成本、能效比值等）均归属「能效」；选其他分类时列表为空。后续扩展容量等分类时只增指标定义，不另开专用页面。
  • 扩展规则：列表与弹窗均按通用指标定义和计算节点渲染。新增能源、计费时段或能效指标时只增加指标定义及节点数据，不新增专用列或专用页面。

交互说明 v2.5 需求文档

关联模块：能效配置 Tab — 配置项清单（一行一个配置项，点「配置」进弹窗）

  • 页面形态（后续可扩展）：本 Tab 是当前对象的配置项清单，每个配置能力只占一行：左侧配置项名称 + 当前配置摘要，右侧「配置」。所有具体操作都在各自弹窗里完成，本 Tab 不就地展开表单，后续新增配置模块按行追加即可。
  • 本期两行：「能源拓扑配置」（摘要为各能源已配置条数，未配置显示「未配置」）、「用能定额考核」。
  • 行内摘要来源：读当前对象的实际配置数据实时生成，弹窗内改完关闭即刷新；切换左树对象时整个清单按新对象重算。
  • 两个入口一份数据：本 Tab 的弹窗只配当前对象，《能源拓扑配置》做跨对象批量作业；两处共同维护能耗计量与供电关系，任一处改动对另一处立即可见。
  • 弹窗里不做的：多视图（空间 / 容量）树切换、Excel 全局导入导出、跨对象批量修改、拓扑版本管理（版本切换 / 新建版本 / 历史版本查看）——这些仍只在《能源拓扑配置》，弹窗头部提供跳转。弹窗内的增删改均落在各能源最新版本上。
  • 用能定额考核：沿用原入口；当前对象在任一能源下都还没有计量关系时，定额保存不可用——可直接在上一行的能源拓扑弹窗补配，不必先跳走。

关联模块：能效配置 Tab — 配置项摘要与单对象能源拓扑口径

  • 行内摘要口径：「能源拓扑配置」行按能源类型列出关系条数，一条都没有时显示「未配置」；摘要只统计当前对象的直接关系。
  • 产物形态：「能源类型 × 拓扑版本 × 拓扑对象 × 成员 × 关系类型」；仅关系类型为能耗计量时记录计量方向。本弹窗读写各能源最新版本。
  • 作用范围：关系表只列当前对象在当前能源下的直接成员；下级对象的下级不在本表展开，需选中该下级对象后再看（计算侧仍递归整棵子树）。
  • 成员类型：关系成员分为表具和下级对象；组件作为物模型实例，可使用自身实例 ID 参与配置。
  • 表具池随能源过滤：默认展示未关联表具，可切换已关联；卡片仅标识可配置的计量 / 供电拓扑关系，搜索统一按表具名称或编码。
  • 归属唯一：同一表具在同一能源的同一版本内只能归属一条能耗计量关系；支持供电的支路可同时建立一条独立供电关系。
  • 今日试算口径：只沿能耗计量关系递归到叶子表具，输入记 +1、输出记 −1；供电关系不参与试算。
  • 原型说明：本页与《能源拓扑配置》各自维护演示数据，页面间状态不互通；真实系统维护同一份关系数据。

关联模块：「能源拓扑配置」弹窗 — 只配当前对象，交互对齐《能源拓扑配置》全量页

  • 配置对象固定：标题栏显示当前对象名称与物模型，弹窗内的一切操作都作用于该对象；要换对象请关闭弹窗后在左树重选。
  • 能源类型 Tab：选项跟随《能源配置》能源类型主数据动态生成（非本页写死），默认选中第一个；角标为当前对象在该能源下的关系条数，0 条表示该能源尚未配置。切换后关系表、对象树配置态、表具池、今日试算一起按该能源重绘。
  • 加关系：从左栏拖入下级对象，或从右栏拖入表具。普通成员建立能耗计量关系；支持供电的列头柜 / 支路自动同时创建能耗计量与供电两条独立关系，无需选择。历史单关系再次拖入时补齐缺失关系。
  • 左栏对象树：只作拖拽来源，点击不切换配置对象；当前对象标「当前对象」且不可拖，已加为成员的节点置灰不可重复拖入，节点前的绿点表示该对象在当前能源下已有关系；支持按名称搜索。
  • 关系类型 / 方向：关系类型只读；双关系成员合并为一行显示“能耗计量 + 供电”。该行仍显示输入 / 输出，且只更新能耗计量底层记录；供电方向固定。
  • 删除 / 试算：点击合并行“删除”表示移除该成员，一次删除当前对象 / 能源下两条关系；仅删某一底层关系不属于本页交互。今日试算只按能耗计量关系递归展开，供电关系不参与计算。
  • 版本口径（2026-08-26）：本弹窗不提供版本切换，读写均落在各能源最新版本上；重算范围遵循统一规则（该版本已生效的覆盖区间）。查看历史版本、为线路改造新建版本，请点头部「批量配置」到《能源拓扑配置》操作。
  • 关闭后：「能效配置」Tab 内该行摘要按最新关系条数刷新。
