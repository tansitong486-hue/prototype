本页说明：本页用于跨对象配置能耗计量关系和供电关系。两类关系独立保存、独立校验；同一列头柜支路可以同时参与两类关系。页头能源 Tab、对象树、关系表和表具池按当前能源类型与当前查看的线路记录展示；今日试算只读取能耗计量关系。全部线路记录（含历史）均可编辑；Excel 导入导出均针对当前查看的线路记录，修改或导入历史记录会按其生效区间重算历史数据。

需求说明 v2.5 需求文档

页面定位与范围（需求 3 / §4.4）：

  • 与《能效视图》的分工：本页面向实施的批量作业（跨对象连续配置、多视图树、Excel 全局导入导出）；单对象配置在《能效视图》「能效配置」Tab 的「能源拓扑配置」行点「配置」，在弹窗内完成。两处产物、校验规则一致，任一处改动对另一处立即可见。
  • 能源分域（核心）：主工作区不是「一套关系看全部能源」，而是「先选能源类型，再只看/只配该能源」。各能源拓扑彼此独立，禁止跨能源混配、混算。
  • 能源类型来源：页头 Tab 不在本页维护，跟随《能源配置》能源类型列表动态扩展（预置电/水/冷量的可删性等规则仍以《能源配置》为准；本页原型示意为当前三类）。
  • 主路径：选能源 Tab → 从视图树选择设备实例或组件实例 → 从表具池拖入对象或表具 → 在“关系类型”列查看只读标签。普通成员只建立“能耗计量”；支持供电的列头柜 / 支路自动同时建立“能耗计量”和“供电”，无需选择。
  • 左树「已配置/未配置」、中间拓扑关系列表、右侧表具池和今日试算均随当前能源 Tab 动态切换；表具池仅标识每个表具可配置的拓扑关系类型。
  • 今日试算按计量关系向下展开到实际表具后做有符号汇总（原型 mock）；按钮固定为「今日试算」，点击即重算。
  • 线路变更记录（2026-08-26 新增）：支撑配电线路技改场景——① 机柜从单路供电改为双路供电；② 配电柜原只计量 A、B 机柜，改造后新增 C 机柜。现场线路变化通过「线路改造」登记一条新记录，自生效日起按新线路出数，改造前历史仍按旧记录解释、不回改；日常纠错与实施期补配仍在当前生效记录内直接改，不要再点「线路改造」。查询能耗 / 成本 / 能效时，跨记录边界的时间段按各记录生效区间分段取对应拓扑聚合后拼接。

交互说明 v2.5 需求文档

关联模块：页头能源类型 Tab 与导入导出

  • Tab 选项来源：读取《能源配置》中的能源类型主数据动态生成（非本页写死）。系统预置电 / 水 / 冷量；在《能源配置》新增类型后，本页自动多出对应 Tab；删除后该 Tab 不再出现（删除约束见《能源配置》：预置三类不可删；已被计费方案等引用时不可删）。
  • 默认选中：进入页面时默认选中列表中的第一个能源类型（原型示意默认「电」）；同一时刻仅一个 Tab 激活。
  • 切换即刷新主工作区：点击任一能源 Tab 后，下方三栏（对象树配置态、计量关系表、表具池）与今日试算立即按该能源重绘，不保留上一能源的关系行/表具列表；线路记录条同步切换为该能源自己的时间线，并默认回到其当前生效记录。
  • 选中对象保留：切换能源时尽量保留左树当前选中对象；中间表改为展示该对象在新能源下的直接关系（可能为空，属正常——表示该对象尚未配置该能源）。
  • 导入 / 导出：页头「导出」快捷下载当前配置；「导入」打开「用 Excel 更新计量关系」三段式弹窗（下载 → 上传 → 检查替换）。跨对象、跨能源，不绑定当前 Tab；Excel「能源类型」合法值以《能源配置》为准。Excel 针对当前查看的线路记录操作：导出内容为各能源当前查看记录的拓扑（未主动切换时即当前生效记录）；导入整表替换的目标同样是各能源当前查看记录，任意记录（含历史）均可作为目标——替换历史记录将按其生效区间重算历史数据，替换未来记录不触发重算。
数据逻辑 v2.5 需求文档

关联模块：能源类型动态展示边界（整页主工作区；主数据来自《能源配置》）

  • 主数据依赖：能源类型名称、累计量单位、实时值单位、成对测点定义、物模型支持关系均在《能源配置》维护。本页只消费：Tab 列表 = 有效能源类型；试算/展示用量单位 = 该能源的累计量单位；表具池与供电源候选按当前支持关系筛选。支持关系只约束本页后续新增与修改；已挂上的能耗计量 / 供电关系不因后来取消支持而删除或失效，再次新增或改存才按最新支持关系校验。
  • 分域键：所有配置读写、占用校验、试算展开都以「当前能源类型 × 当前查看的线路记录」为边界。产物形态为「能源类型 × 线路记录 × 计量对象 × 成员 × 计量方向」；同一对象可按每个已配置能源各建一套拓扑，互不影响。
  • 左树配置态随能源变：● = 该实例在当前能源下已有 ≥1 条关系；○ = 当前能源尚未配置。设备实例与组件实例分别判定，切到另一能源时按该能源重新计算。
  • 组件实例：组件与设备实例使用相同的实例身份和关系规则；所属实例与层级路径仅用于展示。实例树父子层级不自动生成计量关系，也不自动继承或汇总。
  • 中间关系表随能源变：按成员合并列出当前对象 + 当前能源的关系，关系类型只读展示实际存在的标签；双关系成员一行展示“能耗计量 + 供电”，输入 / 输出只作用于其中的能耗计量关系。
  • 表具池随能源变：仅列出当前能源下的表具/组件，并标识可配置的“计量”“供电”拓扑关系类型；关联状态统一由“未关联 / 已关联”筛选表达。
  • 今日试算随能源变：按当前能源计量关系展开到实际表具；用量单位取该能源在《能源配置》中的累计量单位（预置示意：电/冷量 kWh，水 m³）。
  • 查重与校验范围：查重键为「表具（含组件）+ 能源类型 + 线路记录」——同一表具可在不同能源各挂一次，但同一能源的同一条记录内只能挂一次；跨记录互不占用名额。图约束也在「当前对象 × 当前能源 × 当前查看的线路记录」范围内执行。
  • 与导入导出的关系：Excel 文件内按「能源类型」列承载多能源数据，合法值须存在于《能源配置》；页面编辑态仍一次只操作一个 Tab，批量搬迁走全局导入导出。Excel 承载各能源当前查看的线路记录：任意记录（含历史）均可导出、均可作为替换目标，替换后按目标记录已生效区间重算。切换能源 Tab 时离开的能源自动回到其当前生效记录，避免其他能源停在看不见的历史记录上被误替换。
交互说明 v2.5 需求文档

关联模块：线路记录条（能源 Tab 下方，2026-08-26 新增）

  • 默认状态：进入页面或切换能源 Tab 后，默认选中该能源的当前生效线路记录并处于可编辑态——实施期用户无感知，配错表、改方向都直接改当前记录，不必先点「线路改造」。
  • 记录下拉：按生效时间倒序列出该能源的全部线路记录，选项文案为「生效区间 · 状态」；切换后下方三栏（对象树配置态、关系表、表具池）与今日试算立即按所选记录重绘。
  • 状态标签：历史（灰）/ 当前生效（绿）/ 未来生效（橙），由生效日期与今天比较推导，无独立状态字段。未来生效记录到生效日 0 点自动切换为当前生效，无需发布动作。
  • 可编辑性：全部记录（含历史）均可编辑——拖入、改方向、删除成员与 Excel 导入在任意记录下都可用。查看历史记录时顶部展示警示条：修改历史记录将按其生效区间重算历史数据；历史纠错在历史记录内改，现场新发生的线路变化走「线路改造」。审计依据为改造说明与操作留痕，不靠锁定实现。
  • 「线路改造」：仅在现场配电线路发生变化时使用。始终以该能源最新一条线路记录为底稿复制，填写生效日期与改造说明后登记；创建后在新记录里只改发生变化的对象。
  • 「线路变更记录」：查看历次改造列表、与上一段的对象级差异，并承载删除：未来生效记录可删除（二次确认、不重算）；当前生效记录在条数 > 1 时可删除（二次确认）——删除后其生效区间由上一段接管，生效日至今按上一段拓扑重算；仅剩一条时删除置灰（须至少保留一条记录）；历史记录不提供删除。
数据逻辑 v2.5 需求文档

关联模块：线路记录模型与出数规则（2026-08-26 新增）

  • 记录对象：按能源类型各一条独立时间线（电 / 水 / 冷量互不影响）；一条线路记录 = 该能源下能耗计量 + 供电两类关系的整体全量快照。底层对未改动对象沿用上一段记录仅是存储优化，产品层不暴露对象级版本号。
  • 生效规则：天粒度，生效日 0 点切换；记录区间为闭开区间 [本段生效日, 下一段生效日)，无缝无叠。只能在时间线末尾追加新记录；生效日期允许填过去日期（补录已发生的改造），但必须晚于上一段生效日；不支持在两段历史记录之间插入。
  • 统一重算规则：任一记录内容变化，重算范围 = 该记录已生效的覆盖区间。即：当前生效记录内编辑重算生效日至今；历史记录编辑 / 导入重算其整个生效区间；登记未来生效的线路改造不触发重算、到点自动切换；补录过去生效日的改造，提交时二次确认并重算生效日至今；删除当前生效记录后其原区间由上一段接管，并按上一段拓扑重算生效日至今。表具层归档（半小时用量、成本）与线路记录无关，永不因线路变化重算。
  • 查询口径：所有沿拓扑聚合的指标（对象能耗、对象成本、能效、流向、对比、定额）按时间段所属线路记录分段取拓扑聚合后拼接；对象在某段区间内无计量关系时，该区间显示「无计量关系」而非 0；曲线在线路切换点标注「线路变更」标记，悬停可看改造说明。
  • 初始记录：初始化时每个能源自动生成首条线路记录，默认生效日期统一为 2020-01-01（早于任何项目数据，覆盖全部历史区间）；存量项目以现有拓扑作为首条内容，行为与现状完全等价，无迁移感知。
  • 记录内数据边界：左树「已配置/未配置」、表具占用查重（同一表具同一能源只能挂一次）、图约束校验均在「当前能源 × 当前查看的线路记录」范围内判定；上一段占用的表具在新记录中释放后可另行分配。

  • 视图切换：空间 / 容量 / 能效三套树复用同一批实例 ID；设备实例下展示其组件实例，两类节点均可选择或拖入。视图切换不改变当前能源。

交互说明 v2.5 需求文档

关联模块：页头「导入」→ 用 Excel 更新计量关系

  • 面向实施的三段式：① 下载当前配置 → ② 在 Excel 只改「关系清单」→ ③ 上传检查通过后整表替换。跨对象、跨能源；不绑定当前对象/能源 Tab。
  • 弹窗第 1 步提供「下载当前配置」（与页头「导出」同一文件）；已有文件可点「我已有文件，去上传」跳过下载。
  • 工作簿仍含 5 个 Sheet；只允许编辑 Sheet1「关系清单」。设备实例与组件实例均直接使用自身实例 ID；Sheet5 为能源表具对照（含物模型、累计量测点 ID）。
  • 提交语义是整表替换（全量覆盖）：不展示新增/变更/删除比对数量；上传后先检查，全部通过才可「确认替换」。第 3 步只展示通过/未通过结论；逐行问题统一下载「错误文件」查看并修改后重传。
  • 线路记录口径（2026-08-26）：导出与整表替换均针对各能源当前查看的线路记录，任意记录（含历史）可导出、可作为替换目标。替换后的重算范围遵循统一规则——目标记录已生效的覆盖区间：历史记录为其整个生效区间，当前生效记录为生效日至今，未来记录不触发重算（到生效日自动切换）。
请注意：最后确认替换时，各能源当前查看的线路记录会整表换成文件里的内容；文件里没有写到的关系会被删掉。若目标为历史记录，替换后将按其生效区间重算历史数据。上传后会先检查，检查通过才生效。

线路改造
字段说明 v2.5 需求文档

关联模块：「线路改造」弹窗（线路记录条 →「线路改造」，2026-08-26 新增）

  • 使用时机：仅在现场配电线路发生变化时打开；配错表或方向有误应关闭本窗，直接改当前线路记录。
  • 生效日期：必填，天粒度，生效日 0 点起按新线路出数。必须晚于该能源最新一条线路记录的生效日（只能在时间线末尾追加，不支持在历史记录之间插入）；允许填过去日期，用于补录现场已发生的改造——此时提交按钮变为「确认重算并登记」，明确提示将重算生效日至今的对象指标。
  • 改造说明：必填，写清楚这次线路改造的内容（如“A01 机柜单路改双路供电”），供线路变更记录列表与曲线上的线路变更标记悬停展示，是验收与审计的主要依据。
  • 登记行为：以该能源最新一条线路记录为底稿整体复制；登记后自动切换到新记录的编辑态，用户在其中调整发生变化的对象即可，未调整对象自动沿用。
  • 登记后：未来生效记录在到达生效日前可继续编辑、可删除（天然草稿，无独立发布动作）；过去 / 今天生效的记录登记即成为当前生效线路。
仅在现场配电线路发生变化时使用，例如机柜单路改双路、配电柜新增机柜。系统会复制当前线路作为起点，从生效日起按新线路出数，改造前历史保持不变。配错表或方向有误，请关闭本窗，直接在当前记录里改。
生效日期为过去日期：登记后系统将按新线路重算生效日至今的对象能耗、成本与能效指标（表具层归档不受影响）。请确认现场改造确实自该日起生效。
线路变更记录
交互说明 v2.5 需求文档

关联模块：「线路变更记录」弹窗（线路记录条 →「线路变更记录」，2026-08-26 新增）

  • 列表：仅展示当前能源 Tab 的线路时间线，按生效时间倒序；列为生效区间 / 状态 / 改造说明 / 关系数 / 操作。
  • 查看：点「查看」切换主工作区到该记录并关闭弹窗；历史记录同样可编辑，切换时提示修改将重算其生效区间。
  • 与上一段差异：点「差异」展开对象级差异——这次改造动了哪几个对象、各自新增 / 移除了哪些成员、计量方向是否调整；首条记录显示「初始线路」。这是改造验收与审计时的主要视图。
  • 删除：未来生效记录可删除（二次确认，不重算，时间线回落到上一段）；当前生效记录在条数 > 1 时可删除（二次确认）——删除后其生效区间由上一段接管，生效日至今按上一段拓扑重算；仅剩一条时删除按钮置灰（须至少保留一条记录，保证任意时间段有线路可查）；历史记录不提供删除。
