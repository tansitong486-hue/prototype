一、背景与文档定位

1.1 拆分说明

v2.5 原以单册《基于计费的能耗明细系统需求方案与架构》统一承载全部需求。其中数据生产侧（表具核算明细归档、VEE、计量拓扑（含计量方向）、计费属性、对象指标注册指标工厂并查询时计算，以及面向选择器的指标选取服务）与消费侧（存量页面改造取数口径、总览看板、平台侧选择器扩展）关注点不同、评审对象不同、开发归属不同，自本稿起拆分：

v2.5 需求编号全版本连续（1–12），跨册引用时直接以”需求 N”指代。

1.3 总览看板定位

总览看板是 v2.5 面向能源管理员和管理人员的一屏总览入口，用于按当前分析对象和时间范围，集中展示周期能效（含折算指标）、成本，以及用量的趋势分析 / 流向分析。

页面以对象类型、能源计量拓扑、计费方案和下级系统关系为输入，自动生成可展示内容；用户只负责选择视图、对象、能源和时间范围，不需要配置卡片。原独立菜单「能耗流向分析」不再作为侧栏入口，桑基能力落在「能耗趋势与流向」卡内 type「流向分析」。

2.4 用能对比分析：标准化指标对比改版

2.4.1 背景与目标

原页面只能对比「能耗量」单一维度（v2.5 初稿曾扩展为电量 / 成本切换 + 时间粒度选择）。需求 5 将对象能耗 / 成本 / 能效统一注册进指标工厂后，各指标具备一致的对象绑定、时间语义与查询能力；能效视图「指标列表」Tab 又已确立消费侧的指标命名与可见性口径（§4.3.2）。本版把对比维度升级为标准化指标单选：不同对象在不同时间段内，对指标目录中任一指标进行对比。

2.4.2 控件调整：移除三项、新增两项

调整 控件 说明
移除 能源类型（左栏下拉） 能源维度并入指标名称（电能消耗量 / 用水量 / 电费总额…，口径同 §4.3.2「能源类型与计费时段固化进指标名称」），不再先选能源再看数据
移除 统计维度（电量 / 成本切换） 电量、成本本质是两个指标，并入指标目录后该控件冗余
移除 时间粒度（半小时 / 时 / 天 / 月） 对比结果是各时间段的跨度值（区间累计 / 区间比值），底层按哪个粒度查询是取数实现细节，不再暴露

3.7 能效指标总览

  • 能效指标总览以瓦片矩阵展示 PUE、CLF、PLF、OLF、WUE，以及标准煤、碳排放。
  • 指标来源：PUE / CLF / PLF / OLF / WUE 对应指标工厂 §6.3 B1–B5——实时值与各周期值由指标工厂产出，页面只消费指标值、周期趋势与分子 / 分母构成，不在前端计算；下方公式为指标口径说明。标准煤 / 碳排放由各能源用量 × 折算系数汇总产出，页面不重算系数。
  • 能效类指标瓦片展示指标值、等级 / 诊断标签、环比、近 12 期迷你趋势、分子 / 分母构成；折算类瓦片展示指标值、环比、迷你趋势与口径说明，无等级 / 诊断标签。
  • 桌面端首行固定展示 PUE、CLF、PLF、OLF 四张公式卡（园区 / 数据中心且满足规则时），并在卡片间表达 PUE = 1 + CLF + PLF + OLF；WUE、标准煤、碳排放等补充指标展示在后续行。
  • PUE = 总电耗 ÷ IT 系统电量。
  • CLF = 暖通空调系统电量 ÷ IT 系统电量。
  • PLF = 配电系统电量 ÷ IT 系统电量。
  • OLF = 其他系统电量 ÷ IT 系统电量。
  • WUE = 周期用水量(L) ÷ IT 系统电量(kWh)；页面水量默认以 m³ 汇总时，计算前按 1 m³ = 1,000 L 折算。
  • 标准煤 = Σ(各能源用量 × 标煤折算系数)；碳排放 = Σ(各能源用量 × CO₂ 折算系数)；冷量等二次能源系数默认 0。
  • 下级系统解析：上式中的 IT / 暖通空调 / 配电 / 其他系统，取当前园区 / 数据中心在能效视图对象树下按系统类型匹配的结果，下级含下下级（递归整棵子树），不得只取直接一层子节点；同一类型多实例先 Σ 再代入。完整解析与实时/跨度口径见明细引擎册 §6.3.3。
  • PUE、CLF、PLF、OLF、WUE 均为越低越好；折算量 ≥1 万时按「万+单位」缩写展示，悬停显示精确值。
  • PUE 展示「能效 + 等级」标签，WUE 展示「水效 + 等级」标签，CLF / PLF / OLF 展示「诊断 + 档位」标签。
  • 近 12 期迷你趋势随当前时间粒度联动：年粒度展示近 12 月，月粒度展示近 12 日，日粒度展示近 12 小时；鼠标悬停或键盘聚焦数据点时展示「期次：指标值」。
  • 待配置指标不展示等级 / 诊断入口，趋势区展示占位。
  • 系统自身注册的能效指标（对齐 §6.3 各表「注册物模型」列）：
    • 暖通空调系统 / 电力系统 / 其他系统对象上展示各自的 CLF / PLF / OLF 单张瓦片（该系统类型对应的那一个），不展示 PUE / WUE / 标准煤 / 碳排放，也不展示 PUE = 1 + CLF + PLF + OLF 的首行公式关系。
    • 系统自身的 CLF / PLF / OLF 口径为「该系统实例自身电量 ÷ 上溯至最近的数据中心单元 / 园区下 IT 系统电量」（明细引擎册 §6.3.3），瓦片分子 / 分母构成需据此标注为本系统实例，避免与数据中心单元 / 园区级同名指标混读。
    • 同一数据中心单元（或园区）下，单元级 CLF = Σ(其下各暖通空调系统的系统级 CLF)——分母相同，故可加。存在多个同类型系统时单元级与系统级数值不等属口径差异，不是缺陷；瓦片需以文案说明当前口径主体。
    • 上溯不到数据中心单元 / 园区、或其下无 IT 系统时，该瓦片显示「待配置」并提示缺失项。
  • 设备组、设备等未注册任何 B1–B5 指标的对象类型不展示能效指标，整张能效指标总览卡隐藏。判定依据是 §6.3 各表「注册物模型」列，不是写死的「非园区 / 数据中心即隐藏」。

3.8 能效等级标准弹层

  • 触发入口：能效指标瓦片上的等级 / 诊断标签。
  • 弹层展示当前指标、当前对象、当前值、当前等级 / 档位、分级标准或诊断档位、水平说明和优化方向。
  • PUE 按 GB 40879-2021 展示能效等级；WUE 按 GB/T 32910.6-2025 的 WUEev 水效等级展示，本期原型示例暂按 WUE 值代入演示，真实系统需补齐 WUEev 水源修正输入后再判定。
  • CLF / PLF / OLF 展示诊断档位，但弹层不展示标准来源说明。
  • 待配置指标不展示等级入口。

3.9 数据口径

  • 对象能耗、成本、能效指标均消费需求 5 注册的指标工厂产出：历史区间与实时值均查询时按当前拓扑计算；实时值只查当前、不跨时间范围；对象层不落库。
  • 拓扑或表具明细变更后，下次查询自然用最新事实与当前拓扑，页面无需感知对象层重算任务。
  • 支持半小时、时、天、月、年查询粒度。
  • 时、天、月分片读取表具对应粒度 rollup 归集，年由对象月分片累加，均不重新计算差值。
  • 跨天、跨月按本地时间切分。
  • 顶栏粒度与查询 / 图表粒度映射：年视图按月，月视图按日，日视图按小时，时段视图按起止日期范围内小时刻度展示；底层按对应粒度向指标工厂发起查询，由指标工厂读表具归档分片现场归集。
  • 对象切换、时间粒度或日期变化后，当前可见卡片展示加载态；不满足出现规则而隐藏的卡片不展示加载态。

四、平台侧消费指标工厂：需求 10–12 总览

4.3 公共约束（需求 10–12 共同遵守）

4.3.1 核心原则：指标与测点并列，不互相伪装

R5 数据工厂已收敛唯一判据（《数据工厂产品思路》§1）：要告警就是测点，只统计查询就是指标。并明确三条红线：

  • 指标不进物模型、不能转测点、不能被告警规则或控制联动选择（《数据工厂产品思路》§5.3）；
  • 消费端只持稳定 key，分 point key 与 metric key 两套（《数据工厂产品思路》§3.3）；
  • 不做「每个粒度一个虚拟测点」的爆炸（《现场扩展与统计矩阵边界设计》§5.1）。

因此需求 10–12 不采用「把指标注册成虚拟测点、让存量组件无感」的兼容路线（该路线见边界设计 §7 待确认 5，原文已定性为妥协）。改为把选择器从「测点选择器」升级为「数据项选择器」：同一棵对象树内，测点与指标并列为两类可选项，选中项携带类型标记，下游按类型分流取数。

三条理由：

  1. 指标的时间语义约束，测点契约装不下。参数查询中时间段指标只支持 1 小时及以上采样周期；有值聚合复用「求和」，选平均 / 最大等时结果为空值（已按粒度预聚合）；实时指标可选且档位 / 聚合同测点，但需查询计算后出数。伪装成测点后这些约束无处表达，用户会选出查不出数或口径错误的组合。
  2. 伪装即穿透判据。指标一旦在 UI 上与测点无异，配告警只是时间问题，与《数据工厂产品思路》§10「从 UI、API、权限三层禁止指标成为告警源」直接冲突。
  3. 改造面可控。显式双类型影响 3 套选择组件 + 5 个消费点，一次性成本明确；伪装路线的成本会以「口径错乱和越权告警」的形式长期摊在后面。

红线（对需求 10 / 11 / 12 同等生效）：告警规则、联动策略、控制下发、数据补录等写入 / 告警类场景的测点选择器不得接入指标分支。只开放报表查询与组态展示这类只读消费场景。

控件 / 场景 规则

7.4 刷新与失效

组态页是常驻大屏、按秒级轮询刷新，这一点与报表侧按次查询不同，必须单独定规则：

  • 时段指标「实时值」：按半小时粒度对齐刷新，图元显示数据截止时间；不得按秒级轮询反复打指标服务。
  • 时段指标「历史时序」：按绑定的采样周期整点对齐刷新，规则同 §5.5；图元显示数据截止时间。
  • 实时指标沿用固定周期刷新；测点的刷新逻辑完全不变。
  • 失效处理：打开组态时校验绑定有效性（需求 6 接口 4），失效绑定在画布与属性面板标记并提示具体缺失指标，不静默显示空值。
