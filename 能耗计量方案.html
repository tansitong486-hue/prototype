变更概述：AI 节能 v2.5 新建：复用《能耗计量方案》配置能力接入计费能耗明细链路。

本页说明：为当前计量对象（示例：水冷冷水系统-1F）按能源类型配置能耗计量方案；入口来自能效视图对象详情。配置产物为一棵「计量拓扑」（中间层 = 下级计量对象，叶子 = 表具），供对象能耗 / 成本 on-read 聚合查询使用。

需求说明 v2.5 需求文档

页面目的（v2.5 需求 4「计量方案与计量拓扑」）：本版不新建抽象的计量关系模型，而是复用既有《能耗计量方案》配置能力，把配置产物纳入计费能耗明细链路。

  • 两种配置方式：①「各子节点计量能耗」——沿能效视图树选择下级计量对象（系统 → 设备组 → 设备），中间层继续向下展开直至叶子表具；②「仪表计量能耗」——为当前对象直接选择一块或多块计量表具（物模型实例）。
  • 统一产物：两种方式最终都产出同一套计量拓扑，只是树的深浅不同：中间层是下级对象，叶子层是表具。
  • 下游消费（需求 6）：对象能耗 / 成本 = 沿本页产出的计量拓扑递归 SUM 到叶子表具归档明细，对象层不归档、全部 on-read 聚合。
  • 页面级验收要点：保存时强制校验「表具唯一归属一个计量对象」，冲突则拦截保存并给出冲突清单。

交互说明 v2.5 需求文档

关联模块：能源类型 Tab 与计量方式选择

  • 能源类型分块：按当前对象可计量的能源类型（电 / 水 / 冷量）分 Tab 独立配置；各能源的计量方式、成员选择互不影响。
  • 计量方式（单选）：「仪表计量能耗」显示「选择表具」按钮，打开表具选择弹窗；「各子节点计量能耗」显示下级计量对象勾选树。切换方式不清空另一方式下的已选内容，便于比对，保存时仅按当前选中方式生效。
  • 保存：底部「保存」对全部已启用能源统一校验并保存；成功后提示保存成功并刷新「计量拓扑预览」。「取消」返回能效视图对象详情，不保存修改。
状态说明 v2.5 产品推断

关联模块：能源启用开关与配置区状态

  • 启用开关默认关闭：未启用的能源类型不参与计量，其配置区整体置灰不可编辑；开启后恢复可编辑。
  • 未选择成员：已启用但未选任何下级对象 / 表具时，表示当前对象该能源暂无计量成员，拓扑预览中显示「暂未配置」。
  • 已归属他处的表具：在表具选择弹窗中整行置灰、复选框禁用，悬停提示「该表具已归属：xxx」。

    关联模块：下级计量对象勾选树（各能源 Tab 通用）

        数据逻辑 v2.5 需求文档

        关联模块：计量拓扑预览

        • 产物口径：预览展示本页配置产出的计量拓扑：根 = 当前计量对象，中间层 = 勾选的下级计量对象（继续展开），叶子 = 表具。保存成功后按最新配置刷新。
        • 对象层不归档：对象能耗 / 成本不落库，查询时沿本拓扑对表具归档明细（半小时 / 时 / 天 / 月）递归 SUM，on-read 聚合（需求 6）。拓扑一变，对象历史口径在下次查询自动一致，零回填。
        • 历史随当前拓扑（产品已接受口径，§9.4）：对象查询始终沿【当前】拓扑聚合。表具改绑到其他计量对象后，其全部历史能耗 / 成本随之归到新对象名下、旧对象对应历史相应减少。本期不做计量拓扑生效版本；需「历史归属冻结」的场景（如用能定额考核）须另行立项。
        边界与异常 v2.5 需求文档

        关联模块：保存校验 — 表具唯一归属强制查重

        • 唯一归属约束（§7.1）：一个表具只能归属一个计量对象，不得同时挂到两个计量对象 / 两处拓扑，从源头杜绝 on-read SUM 的重复计量。
        • 查重范围：保存时对「直接选择的表具」与「选下级对象后展开到的叶子表具」统一校验；与其他计量对象已占用的表具冲突即拦截。
        • 冲突处理：保存被拦截，弹出冲突清单（表具名称 + 已归属计量对象 + 冲突来源），本次不保存任何能源的配置；用户调整选择后重新保存。
        • 换表不算重复计量（§6.2）：换表 = 同一计量对象内旧表下线 + 新表上线，旧表停走、新表起走，二者归属同一对象、挂同一拓扑，不违反唯一归属约束；不支持通过改绑跨对象搬历史。

        字段说明 v2.5 需求文档

        关联模块：「选择表具」弹窗；入口：各能源 Tab「仪表计量能耗」方式下的「选择表具」按钮

        • 数据来源：当前能源类型在能源配置中定义的物模型实例（物模型实例 = 表具）；仅展示挂有该能源标准累积量测点的实例。
        • 列说明：物模型（表具所属物模型名）、表具名称（实例 / 组件名，支持顶部输入框模糊搜索）、归属计量对象（未归属 / 本对象 / 其他对象名）。
        • 已归属其他对象的行：整行置灰、复选框禁用不可选，悬停提示「该表具已归属：xxx」——与保存查重同一套唯一归属规则的前置拦截。
        • 回显：再次打开时勾选状态按当前已选表具回显；多选，点「确定」写回已选列表，点「取消 / ×」放弃本次勾选变更。
