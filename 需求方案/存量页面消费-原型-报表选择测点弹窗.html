视图 三视图选择

适用场景：③ 按实例添加　｜　④ 按模型添加
  • 做：「按实例添加」「按模型添加」加空间 / 容量 / 能效三视图；按模型首栏改「选择对象范围」，范围按当前视图子树递归；能效 / 容量下中间栏称「选择对象类型」。
  • 不做：外层「选择测点」清单（视图部分不动）；节点-测点树视图（已有，对齐复用）。
  • 规则：切视图不清空已选；按「实例 + 类型 + 标识」去重；未配置视图置灰提示不隐藏。

指标 实时指标选择

适用场景：① 参数查询　｜　② 外层弹窗　｜　③ 按实例添加　｜　④ 按模型添加
  • 做：两种添加方式开放本次需求提供的实时指标；外层表新增“类型”列；参数查询沿用测点的采样周期、统计方式和结果展示逻辑。
  • 不做：查询指标选择与查询；指标专属查询参数；模型级合计或平均值。
  • 规则：按实例只显示可计算的实时指标；按模型批量添加 N 条实例数据项；持久化按“类型 + 标识”保存；加载方案时校验失效项并提示。

视图切换规则
  • 视图下拉固定为空间、容量、能效三项，树结构与节点-测点树保持一致。
  • 三视图是同一批物模型实例的不同树结构，节点可跨视图复用。因此切换视图不清空已选清单，用户可在空间视图选几个、切到能效视图再选几个。
  • 已选清单按「实例 + 类型 + 标识」去重，同一实例的同一数据项在不同视图重复勾选只保留一条。
  • 未配置的视图在下拉中置灰并提示先配置视图，不隐藏。
指标部分 — 指标叶子（树上挂载规则）
  • 指标绑定在对象实例上（园区 / 数据中心 / 系统 / 设备组 / 设备），不挂在组件或测点下。指标叶子直接挂在对象节点下，与设备子节点同级同层——不套「指标（N）」分组节点、不新增层级，仅靠图标与类型标签区别于测点。
  • 某对象下出现哪些实时指标，由该对象所属物模型（含继承链）与指标注册关系决定；选择器不为具体对象类型写死分支。
  • 实时指标勾中后直接进入已选清单，不增加二次参数面板；查询指标不展示。
  • 按实例添加不提供“仅有值 / 全部”与业务分类筛选：只展示算得出结果的实时指标；缺输入的指标不出现在树上。

三栏选择规则
  • 第一栏：「选择空间」→「选择对象范围」，新增三视图切换。范围解析按当前视图子树递归（含下下级），不只取直接一层子节点。
  • 第二栏：空间视图下保持现状「选择设备分类」（IT设施 / 场地设施 / 备品备件 / 软件 → 二级分类 → 物模型）；能效 / 容量视图下语义放宽为「选择对象类型」，以便按系统类型（暖通空调系统 / 电力系统等）批量选取。
指标部分 — 按物模型批量添加实时指标
  • 选定范围 + 物模型 + 实时指标后，一次性加入该范围内所有该模型（含继承子模型）实例的同一实时指标，与现有「某模型所有实例的对应测点」完全对称。这是明细引擎册「模板化绑定（绑 (物模型, 指标)，切换实例即复用）」在报表侧的落点。
  • 可选指标列表仅包含该物模型上注册且属于本次需求范围的实时指标。
  • 第三栏按测点、实时指标分组展示；查询指标不展示。
红线：只批量添加，不产出模型级合计值
批量添加得到的是「N 个实例 × 同一指标」的 N 条独立数据项，不是该模型全部实例的合计或平均。原因：同一块表具可能同时落在多个实例的计量拓扑内，跨实例合计会绕开叶子系数与重复路径校验形成重复计量。横向汇总由用户在报表内自行处理。

参数查询最终规则
  • 保持现网参数查询的页面结构：顶部单行查询条件，结果区支持表格 / 曲线切换，表格按对象、数据项和聚合方式形成多级表头。
  • 参数查询是默认入口；点击“测点选择”的选择器后打开外层“选择测点”弹窗，确定或取消后返回参数查询。
  • 选择弹窗的可选范围只包含测点和本次需求提供的实时指标，查询指标不展示、不选择、不查询。
  • 实时指标与测点共用采样周期和聚合方式；混合选择后，每个数据项作为独立结果列展示，名称和单位沿用各自定义。
  • 重置、查询、保存、快捷查询、生成数据报表和分页等现有能力保持不变。
