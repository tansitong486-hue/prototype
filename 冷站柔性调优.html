版本信息

当前版本：v2.0

更新日期：2026-05-08

v2.0 变更：适配风冷冷水系统：寻优规则配置中的模拟量寻优规则收敛为「风冷冷水机组冷冻水出水温度 + 冷冻水泵/二次冷冻水泵频率」，隐藏冷却水泵、冷却塔等冷却侧设备及参数；投入/投出配置移除冷却水测点、冷却泵组、冷却塔组；寻优记录和下发记录不再展示冷却侧变量，室外扰动变量展示为室外干球温度。

v1.0 基线：页面由古典 Axure「冷站柔性调优」迁移至本 AI 单页。三策略卡、关键指标、寻优/下发双 Tab、规则侧栏与下发弹窗。

v1.8 变更：「寻优规则配置」面板重构，对齐当前系统实际字段——新增仿真模型、寻优器（L-SHADE / SLSQP，切换后参数联动）、种群初始化数量、种群最终数量、最大迭代数（SLSQP 改为最大迭代数 + 收敛精度）、模拟量寻优规则表格；移除机房寻优错误复用的主控制/辅助控制/K_safe 字段。新增「寻优目标偏好」区块：三个业务化滑块（安全余量偏好 λ₁、设备切换容忍度 λ₂、参数平稳偏好 λ₃），对应多目标加权寻优方案（v1.8 需求文档《寻优目标函数优化方案设计》）；柔性寻优下 λ₂ 置灰不可用。

v1.8 补充：冷站配置支持二次冷冻泵频率参与寻优——模拟量规则表新增「二次冷冻水泵 / 频率反馈」；投入/投出增加「二次冷冻泵组」；关键指标与下发记录展示二次泵变频设定。

字段说明 v1.8 引用自需求文档

关联模块：规则配置右侧面板 —「寻优规则配置」Tab

寻优周期 T_opt：定时触发寻优计算的时间间隔（分钟）。

仿真模型：单选，绑定当前冷站使用的风冷冷水系统仿真模型实例。

安全边界：单选，选择当前项目/园区下已配置的安全边界方案。

寻优器：选择后下方参数联动切换——L-SHADE：种群初始化数量 + 种群最终数量 + 最大迭代数；SLSQP 梯度优化器：最大迭代数 + 收敛精度（小数位数）。

模拟量寻优规则：风冷场景保留风冷冷水机组冷冻水出水温度、冷冻水泵频率、二次冷冻水泵频率；冷却水泵、冷却塔频率、冷却塔风机开机数等冷却侧控制量不展示。

【v1.8 新增】寻优目标偏好：多目标加权寻优配置，对应目标函数 J = P_norm + λ₁·C_safety + λ₂·C_switch + λ₃·C_swing。三个滑块业务含义：

  • 安全余量偏好（λ₁）：0.00～0.50，默认 0.10；越大寻优结果越远离安全硬边界。
  • 设备切换容忍度（λ₂）：0.00～0.50，默认 0.15；柔性寻优不涉及设备启停，本页置灰不可用，全局/长周期寻优中生效。
  • 参数平稳偏好（λ₃）：0.00～0.30，默认 0.05；越大寻优结果越倾向与当前值靠近，减少控制参数振荡。

三项权重均为 0 时行为与原单目标最小功率等价（向下兼容）。
