交互说明 v2.5 产品推断

关联模块：能源 Tab · 多视图对象树 · 关系表 · 今日试算 · 表具池

  • 能源 Tab：切换后左树配置态、中间表、表具池、今日试算全部跟随当前能源。
  • 视图切换：空间 / 容量 / 能效三套树，节点 ID 可跨视图复用；拖入关系表的是对象实例。
  • 配置态：● 当前能源已有 ≥1 条关系；○ 当前能源尚未配置。
  • 类型：仅「表具」「下级对象」两类；组件属于表具之下，名称列用「所属表具」标明，类型仍标「表具」。
  • 拖拽：左树仅已配置对象可拖入为下级；右池拖入表具（含其下组件）行；默认方向输入。
  • 表具池：默认只看未占用；可筛选已占用/全部；支持设备与组件；上千条时分页（每页 20）。
  • 表具占用：同一能源下一块表具/组件只能挂一次，标签统一为「已占用」。
  • 今日试算：结果区常显；点击「今日试算」按当前拓扑重算叶子有符号用量；可跳转表具能耗明细。

交互说明 v2.5 需求文档

关联模块：页头全局「导入」

  • 导入导出跨对象、跨能源；不绑定当前对象详情。当前全局拓扑由页头「导出」按钮下载；导入弹窗不重复提供导出，直接上传编辑后的全量配置文件。
  • 导出工作簿固定包含 5 个 Sheet：关系清单、能效视图对象、空间视图对象、容量视图对象、能源表具清单。对象与表具均导出 `0_565` / `0_708` 这类业务实例 ID，不导出页面树节点 key 或 `AC_Meter_08` 这类内部编码。Sheet5 固定为“能源类型 / 表具实例 ID / 表具名称 / 组件名称 / 测点 ID”，组件名称仅组件型表具填写，测点 ID 为该表具或组件的具体累计量测点。
  • Sheet1「关系清单」是唯一配置编辑页；第 1 行固定展示写入规则，第 2 行为 8 列表头，第 3 行起填写关系。组件名称放在「成员名称」与「计量方向」之间；组件关系按“所属表具 + 组件名称”识别，如“列头柜 1 + 支路 1”，不重复所属表具名称。
  • 必填校验：计量对象实例 ID、能源类型、成员类型、成员实例 ID、计量方向始终必填；成员为组件型表具时，组件名称条件必填且必须命中 Sheet5 对照项。
  • 导入采用全量覆盖：Sheet1 未保留的现有关系视为删除；上传后真实校验工作簿结构、必填字段和对照关系，失败时展示 Sheet、行号与原因且禁止提交。预校验失败后可导出错误文件：保留上传文件内容，在问题所在 Sheet 末列增加「问题原因」，同一行的多个原因合并展示，修正后可直接重新上传。
