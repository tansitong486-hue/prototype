需求说明 v2.4 需求文档

页面范围（对应需求 §九 阶段三·验证，按评审意见修订）：

  • 验证 = 基于工况快照的逐工况点比对：执行阶段每个工况点运行稳定后已保存一份工况快照（对整个水冷系统走一次实时仿真校验的全参数存档，含各对象/指标的当前实际值 + 当时旧模型的模拟预测值）。模型训练完成后，用户从工况点列表中选择某个工况点发起验证，系统针对该快照的同一运行条件再调用一次实时仿真（新模型），得到本次预测值。
  • 三组数值对比：当时实际值（真值基准）vs 训练前预测值（训练前旧模型）vs 本次验证预测值（训练后新模型），并分别给出新旧模型相对实测值的偏差，体现训练后精度改善。
  • 不做回流重训：重训在既有「机理模型训练」能力中完成（手动重训或自学习自动触发），属模型训练过程（§9.3）；本页只提供训练完成后的验证入口，以及训练未完成时的跳转引导。
  • 不做验证结果入库：验证结果仅在线展示，不建表、不保存（§9.2；§十三 范围边界表「验证结果入库」一行）。
  • 不设合格判定标准：本页不做"达标/未达标"或置信等级判断，验证动作不驱动探索策略的状态流转（草稿 / 执行中 / 已完成 / 已中止均不受本页影响）。「已完成 / 已中止」的策略均可对已有工况快照发起验证——已中止是终态，不影响验证入口。

提示

1、探索执行时，每个工况点运行平稳后，系统都自动保存了一份「快照」：记录当时整个冷站各项参数的实际值，以及当时模型算出的预测值。

2、模型训练完成后，在下方列表选一个工况点、点「发起验证」：系统会用训练后的新模型把这个工况重新算一遍，和快照里的实际值、训练前的预测值放在一起对比——预测值越接近实际值，说明训练后模型越准。

3、对比结果只在本页查看，不会保存，也不影响策略状态；本页只展示数值和偏差，不做"合格 / 不合格"的判定。

状态说明 v2.4 产品推断

关联模块：训练衔接状态 / 验证加载 / 空态（本页默认演示"训练已完成 + 有工况快照"，以下状态不在默认演示中渲染，仅作规则说明）

  • 训练未完成态：该策略绑定仿真模型尚未应用重训后的新模型时，状态条展示中性引导态（蓝色信息态，非红色错误态——训练未完成是正常过程）：标题"训练尚未完成"，说明"请等待「机理模型训练」完成本策略样本的重训（或等待自学习自动完成）后再发起验证"，提供「前往机理模型训练」按钮跳转 机理模型训练.html；此时工况点列表照常展示，但「发起验证」按钮置灰不可点，避免用旧模型做无意义的比对。
  • 验证加载态：点击「发起验证」后，按钮置灰显示"验证中…"，对比表区域覆盖半透明遮罩 + 加载动效（针对选中快照调用实时仿真需要数秒），期间不可重复点击、不可切换选中工况点。
  • 验证失败：实时仿真调用超时/异常时，遮罩替换为失败提示 +「重试」按钮；保留上一次已展示的对比结果，不清空。
  • 尚无工况快照的空态：若该策略执行期未产生任何已记录工况点（如执行即被中止），本页工况点列表展示空态插画 + "该策略暂无已记录工况点"文案，「发起验证」按钮置灰，对比表区域不渲染。

数据逻辑 v2.4 需求文档

关联模块：工况点列表列表

  • 数据来源：执行运行的每步记录表（需求 §4.1 表⑤ exploration_step_archive）——执行阶段每个工况点运行稳定后，系统查询绑定仿真模型的最新结果整体存档（sim_snapshot，含全系统各对象/指标的"当前实际值 + 模拟预测值"）。本列表按记录时间正序列出该策略下全部已记录工况点。
  • 被探对象口径：探索按设备类型同时下发，同类型运行中设备（如 1号、2号冷却塔）在同一工况点收到相同目标值，故被探对象按设备类型展示并注明同时下发的设备实例。
  • 快照参数数：该快照内保存的对象/指标条目数，来自全系统实时仿真返回体，用于提示快照是"全系统级"存档而非仅被探变量。
  • 验证状态：前端会话内标记——"未验证 / 本次已验证"仅表示本次打开页面后是否对该工况点发起过验证，不保存、不跨会话保留。

交互说明 v2.4 需求文档

关联模块：工况点列表 —「发起验证」按钮与选择交互

  • 「发起验证」点击语义：针对选中工况快照的同一运行条件再调用一次实时仿真（训练后新模型），得到本次预测值——不触发下发、不动设备、不影响任务状态；与执行阶段的记录动作使用同一仿真模型，只是这次是训练后的新模型在算。
  • radio 单选切换：点击行任意位置或 radio 均可切换选中工况点（一次只能选一个）；切换仅改变选中态，不自动发起验证，须点击「发起验证」才触发比对；验证加载期间禁止切换。
  • 验证状态列联动：某工况点验证完成后，其"验证状态"由"未验证"变为"本次已验证"，同时下方对比表标题与内容切换为该工况点的三组数值对比结果。
  • 与《仿真校验》页"重新校验"的区别：该页是对当前实时运行状态发起校验；本页是对历史已记录工况点发起验证，比对基准是记录时刻的实测值，两者入口与语义不同。
边界与异常 v2.4 产品推断

关联模块：验证行为边界

  • 不判定：本页不做"达标/未达标"判定、不做置信等级分级、不设合格判定标准；偏差列统一用中性色 + 正负号表达方向，不用红/绿判色（该配色隐含"合格/不合格"语义，评审与开发时不要把《仿真校验》页的判定逻辑带入本页）。
  • 不保存：本次验证预测值与偏差仅在线展示，不写入记录表或任何新表；刷新页面后本次验证结果不保留。
  • 多次验证覆盖展示：同一工况点重复点击「发起验证」，仅用最新一次结果刷新对比表展示，不保留历史验证记录、不做多次结果对比。
数据逻辑 v2.4 需求文档

关联模块：验证对比表 —— 三列取值口径（§九 + 评审确认）

  • 当时实际值：取自选中工况快照（sim_snapshot）中的"当前实际值"，即该工况点运行稳定时刻的真实运行数据，作为比对的真值基准。
  • 训练前预测：取自同一快照中的"模拟预测值"，即记录时刻旧模型（训练前）对该工况的预测。
  • 训练后预测：点击「发起验证」后，系统针对该快照的同一运行条件再调用一次实时仿真（新模型已生效于绑定仿真模型"1号集成冷站仿真"）返回的预测值。
  • 训练前偏差 / 训练后偏差：分别 = 训练前预测值 − 当时实际值、本次预测值 − 当时实际值；同一真值基准下两列偏差直接可比，训练后偏差收窄即说明补样重训对该工况段的精度改善（尤其被探的冷却塔高频段相关指标）。
  • 展示范围：快照为全系统存档（100+ 参数），页面默认展示与被探变量强相关的代表性对象/指标节选，完整参数可滚动/展开查看（原型仅演示节选）。
