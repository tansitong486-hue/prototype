模型训练

数据逻辑v2.9需求文档

关联模块：评估效果（8 列）

  • 列与字段：噪声 σ（noise_sigma）｜评估 RMSE（eval_rmse）｜相对误差 %（relative_error，模板配 MAPE 或 CV(RMSE)）｜幅度异常 %（slope_out_of_band_max）｜趋势反向 %（slope_opposite_max）｜平顺度 ‰（smoothness_ratio）｜超范围异常 %（extrap 反向 / 不响应 / 幅度异常三项取最大）｜性能 s（fit_seconds_at_10k）。
  • 分项评级、无综合评级：良好绿 / 注意橙 / 不佳红 / 未评估灰；噪声不着色；评估 RMSE 与相对误差同色；趋势反向列取趋势反向与不响应较差一级；超范围、性能分别取组内最差。
  • 阈值（良好 / 注意上限）：相对误差 10% / 20%；幅度异常 20% / 50%；趋势反向 5% / 20%，不响应 >50% 为注意；平顺度 5‰ / 30‰；性能 30 s / 120 s 且单次预测 5 / 20 ms。阈值由接口下发。
  • 格式：原单位 3 位有效数字；% 与 ‰ <10 一位小数、≥10 取整；无值「--」，未训练成功「-」，无新报告的老模型显示旧四项。
  • 悬停：逐项数值 + 单位 + 评级 + 一句含义，底部噪声底提示（RMSE ≤1.5σ / 读数不变 >30% / 不足 30 对）；点击打开评估弹窗。

数据逻辑v2.9需求文档

关联模块：C1 / C3 行 — 区域模型与逐点读数映射

  • 区域模型：通道份额 a(i,A) 按稳态行 NNLS 辨识；条件数 > 1e3 或样本 < N_min 取拓扑等分。
  • C1：T_c = Σ g(i,c)·s_i·T_sa,i + (1 − Σ g(i,c)·s_i)·T_hz,A + o_c；g 只在 feedsAir 边上，Σ ≤ 1；o_c ∈ [−6, 6]℃。
  • C3：T_h = Σ v(h,A)·T_hz,A + o_h；v ∈ [0, 1.5]，o_h ∈ [−15, 15]℃。
  • 未运行机组列剔除；样本不足或秩亏回落 L0（区域温度 + 偏置）。
  • 冷 / 热点按所属通道 aisleType 区分。

数据逻辑v2.9需求文档

关联模块：迁移评估与该设备选用

  • 用目标设备评估窗口内全部可用行跑源模型。
  • 迁移误差 = RMSE + 相对误差，阈值同评估误差；跨设备误差比 = 目标 RMSE ÷ 源 eval_rmse（1.5 / 3）；物理规律三项同训练口径；额定参数最大相对差（0 / 5%）；工况覆盖、系统偏差（占比 >50% 提示）只作提示。
  • 评估不佳 = 迁移误差或物理规律任一不佳。
  • 状态：未评估、排队（第 n 位）、评估中、评估失败（原因原文）、样本不足（<288 行）、结果不完整、过期（源模型重训或额定参数变化）。
  • 该设备选用：当前使用的模型及其 RMSE；开启 / 关闭后会用的模型。

  • 服务勾选：待同步服务平铺展示，每行展示「设备实例 / 预测类型」。静态属性全部录入的服务可勾选；缺任一静态属性的服务置灰、不可勾选，并在行内精确提示缺失的设备实例·属性名。
  • 已选数量：底部实时展示已选择服务数量；仅统计可同步且已勾选的服务。
  • 确定：至少选择 1 个服务后可点；批量创建固定“机理模型 + 混合增强模型”两槽位模板，不可重复提交。未选任何服务时「确定」置灰。
  • 取消：关闭弹窗，不提交；再次打开时重置为初始状态。
数据逻辑 v2.3 需求文档

关联模块：模型同步 — 服务模板规则

  • 列表来源：依据节点树选中的设备实例 + 系统预定义预测参数类型生成；同一「设备实例 / 预测类型」已存在模型服务时不重复创建。
  • 静态属性校验：创建该预测模型服务所需的静态属性全部必填；缺任一属性时该服务不进入可提交范围，避免缺失情况，不做缺省/估算兜底。
  • 跨设备缺失归因：聚合/管路类模型（如制冷单元压差取主机+板换额定属性）的缺失须按所属子设备分别列出具体实例与属性，每条缺失提供"去补齐"跳转入口直达对应设备/设备组对象维护页。
  • 模板来源：由模型类别自动派生固定两槽位：机理模型固定只读；混合增强模型默认机理模型，无机理公式类别默认 SVR。
  • 新增命名规则：{设备实例}–{预测类型}预测模型；数据集起始日取弹窗所选「数据集开始日期」。

  • 数据集开始日期：必填，默认当天；作为同步后混合增强模型首次训练/数据窗口的默认起始日期。

字段说明 v2.2 产品推断

关联模块：训练失败原因弹窗；入口：主表或历史版本中的「查看原因」。

字段说明
错误码用于定位失败类型，面向排查与沟通；为空时展示「—」，不影响用户查看其他信息。
错误描述说明本次训练失败的直接原因，需用业务可理解语言描述，例如数据量不足、异常值导致算法收敛失败等。
失败时间展示该训练任务判定失败的时间，便于与历史版本、日志和数据质量问题进行交叉核对。
状态说明 v2.2 产品推断

关联模块：训练失败原因弹窗状态与异常处理。

  • 正常展示：弹窗打开后展示错误码、错误描述和失败时间；信息较长时允许在弹窗内换行展示，不截断关键原因。
  • 原因缺失：若失败详情未返回，弹窗保留标题与操作按钮，并提示「未获取到失败详情，请联系运维人员查看训练日志」。
  • 重新训练：点击后关闭失败原因弹窗并进入训练配置处理链路；若后续跳转失败，应给出明确失败提示并保留当前上下文。
