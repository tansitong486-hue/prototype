批注版本：
版本信息

当前版本：v1.0（初版）

更新日期：2026-03-26

变更概述：总览看板增加标准化批注与版本筛选；各能耗/能效图元在卡片上方配有独立「图元说明」批注；能耗成本折线、用电堆叠柱与环形图元使用 Chart.js 绘制，支持悬停提示与图例外环交互；PUE 半圆仪表仍为矢量示意。

本页说明：点击右下角「批注」进入批注模式；主网格内每一类图元均有对应批注块。子页「看板配置」维护对象树、图元勾选与画布 Tab。

需求说明 v1.0 产品推断

面向运营与管理人员，在选定视图（空间 / 能效）、数据中心与时间范围下查看能耗统计 / 能效总览两类 Tab 下的指标卡片（本原型以静态示意为主）。用户可通过「看板管理」进入配置页，调整展示的图元与布局。本期原型不覆盖实时告警流、单卡下钻详情、导出报表等能力，若评审需要请另列单据。

交互说明 v1.0 引用自古典原型

关联模块：顶栏筛选、时间粒度与日期、副栏 Tab、看板管理

  • 视图：下拉在空间视图（按物理空间/机房拓扑维度组织）、能效视图（侧重 PUE、能效指标与对比）之间切换；切换后下方卡片数据范围与默认图元组合随所选视图刷新（原型未接真实数据，两类下卡片布局可一致，仅作语义区分）。
  • 数据中心：点击绿色触发器展开面板；可先切换顶部数据中心 pill，再在网格中选择子系统（IT / 电力 / 暖通空调 / 其他）；进入子系统后列出设备，点选设备后触发器展示「数据中心 / 子系统 / 设备」并收起面板，看板范围随所选对象更新（示意）。
  • 时间粒度：年 / 月 / 日 / 时段四段切换；右侧日期 pill 文案联动为：年→YYYY，月→YYYY-MM，日 与 时段→YYYY-MM-DD（时段在本原型中同样只精确到日，不展示起止时刻）。
  • 用量与成本图表联动：选择年时，用量与成本/趋势横轴按月；选择月时按日；选择日时按小时（所选日 24 小时内示意）；选择时段时 pill 展示起止日期，依次点选开始/结束日期，图表仍按小时粒度在范围内均匀取刻度示意。
  • 日期 pill：点击后按当前粒度调起浏览器原生 month 或 date 选择器；变更后 pill 与内部状态同步。
  • 能耗统计 / 能效总览：副栏 Tab 切换当前看板语义（原型内仅切换选中态，卡片集一致，真实系统可按 Tab 过滤图元）。
  • 看板管理：进入「看板配置.html」编辑对象树、勾选图元与画布 Tab；保存后返回本页（配置页行为见该页批注）。
数据逻辑 v1.0 引用自古典原型

关联模块：看板图元（总览）

  • 分析对象：数据中心选择器支持数据中心 → 子系统 → 设备三级；未选到设备时统计范围默认为当前数据中心；选定设备后各图元指标按该对象聚合，细则以需求为准。
  • 与看板管理：下列每一类图元均可在「看板配置」中勾选是否展示；各图元的目的、字段含义与古典稿对应关系见该卡片正上方的「图元说明」批注。
状态说明 v1.0 产品推断

关联模块：卡片与图表

  • 加载中：真实系统可对整页或单卡骨架/转圈；本原型为静态数据，无加载态。
  • 无权限 / 无数据：某图元对当前对象不适用时可隐藏卡片或展示「暂无数据」；本原型用标签（如「仅园区/数据中心」）提示适用范围。
边界与异常 v1.0 待确认

关联模块：时间与对象范围

  • 时段粒度：若业务需选择自然日内的起止时刻，需在需求中单列，本原型不展示时刻段。
  • 浏览器兼容：极旧浏览器可能不支持 showPicker，需降级为点击隐藏 input 触发选择（本页已做基础兼容）。

图元说明 v1.0 引用自古典原型

关联模块：能耗成本（IT用电量）图元

  • 对象范围：支持在任意对象上（园区、数据中心、设备组、设备）展示能耗成本图表。
  • 展示规则：根据对象下已关联计费方案的测点动态展示；当对象存在 2 个测点（IT 用电量、总电量）且都关联计费方案时，应分别展示对应图表；若对象下测点均未关联计费方案，则无需展示。
  • 图表名称：能耗成本（#测点名称#）。
  • 卡片内容：左侧展示筛选时间段内能耗成本总和，保留 2 位小数；右侧展示按时间粒度聚合的成本趋势。
  • 单一计价样式：当测点所属计费方案为单一计价规则时，按当前卡片样式展示总成本与单条成本趋势。
  • 峰平谷样式：当测点所属计费方案为峰平谷或尖峰平谷规则时，应切换为分时成本展示样式；除总成本外，还需体现峰 / 平 / 谷（以及尖峰场景下的尖）各时段成本分布与趋势，前端样式按古典原型对应的峰平谷展示稿执行。

图元说明 v1.0 引用自古典原型

关联模块：能耗趋势（电）图元

  • 用途：在顶栏筛选时间范围内，按时间序列展示用电量的堆叠柱状趋势；柱内各段对应计量方案下的分项（如按子节点或按计量对象拆分，见古典规则）。左侧汇总为该时间段内能耗量总和，单位取当前能源（电）单位，小数位规则与古典一致。
  • 动态出现：对象启用哪种能源的能耗计量，就看板上出现对应「能耗趋势（能源名）」卡片；未启用则不展示。可同时存在电、水等多张趋势卡（本原型仅示意电一张）。
  • X 轴粒度：与顶栏时间维度联动：年→按月，月→按日，日→按小时（当日 24 小时内示意），时段→起止日期范围内按小时均匀刻度示意；与「能耗成本」趋势图同一套规则。古典另有按筛选区间自适应的规则时，以实现为准。
  • 适用范围：古典写明支持园区、数据中心、设备组、设备等任意对象。
  • 古典对应：「能耗趋势」页堆叠柱状图元。
