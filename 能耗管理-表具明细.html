数据逻辑 v2.5 需求文档

关联模块：明细表格 — 取数与差值规则（§5.2 / §5.3 / §5.4）

  • 取数：每个半小时槽只取槽尾值（槽末累计读数），忽略槽内中间采样点。
  • 差值：本槽用能量 = 本槽尾值 − 上一槽尾值；相邻两槽相减、不跨槽取值，任一侧尾值取不到即标缺失，不向前追溯更早尾值凑差值。
  • 首个尾值仅作基线：表具首次产生尾值的槽（新接入 / 首配累积量测点 / 换表后新表首槽）无上一槽尾值可减，该槽不产生用能量，从下一槽起计差值。
  • 幂等键：每条明细以「表具 + 能源类型 + 时间槽」唯一定位，支持指定时间窗重算覆盖（表具在某能源类型下对应唯一累积量测点，键无需测点维度）。
  • 多粒度：时 / 天 / 月行由半小时明细累加归档生成，只累加、绝不在高粒度层重算差值；rollup 行「期末尾值」列展示该区间最后一个有尾值槽的尾值（整区间无尾值则显示「—」），仅作核对参考，不参与 rollup 计算。
  • 成本列：表具半小时成本 = 半小时用能量 × 该时段【当时生效计费方案】单价，随电量明细归档（§8.2）；缺失 / 坏值槽无有效用能量，成本同为「—」。
边界与异常 v2.5 需求文档

关联模块：明细表格 — 数据质量校验（§6.1，本期最小集）

类型规则处理
尾值缺失本槽或上一槽尾值取不到（离线 / 未上报）该槽标「缺失」，不产生有效用能量，不参与聚合；不作 0，不跨槽追溯
单调性本槽尾值 < 上一槽尾值（尾值回退）该槽标「坏值」
增量上限单槽差值 > 该表具生效上限（电默认 1500 kWh / 半小时，支持按表具 / 能源类型配置，未配置取默认；本期用固定 / 可配上限，不用均值 / 标准差）该槽标「坏值」
坏值处理坏值 / 缺失槽不参与聚合标「数据异常 / 缺失」，可在数据质量自检页识别；不静默当 0
  • 坏值槽的尾值仍可作下一槽基准：质量标记作用于用能量（差值），不否定尾值本身；只要本槽尾值存在（非缺失），即可作下一槽减基准，下一槽差值独立判定。只有「尾值缺失」才不能作基准、才向后传递缺失。
  • 断点续传（晚到 / 批量补传）：对受影响时间窗幂等重算；重算范围须含缺口紧邻的下一槽（其基准尾值被补回），首槽须读缺口前一槽尾值作基准；补传后仍无尾值的槽保持「缺失」，并同步刷新受影响槽的时 / 天 / 月 rollup 与成本。
  • 本期不做估算补值：坏值 / 缺失由人工修正或补传后重算处理。
状态说明 v2.5 需求文档

关联模块：明细表格 — 数据质量状态列

  • 正常（绿）：相邻尾值差值通过全部校验，计入聚合。
  • 缺失（橙）：本槽或上一槽尾值取不到；用能量与成本显示「—」，悬停提示原因（尾值缺失 / 上一槽尾值缺失）。
  • 坏值（红）：尾值回退或差值超上限；用能量与成本显示「—」，悬停提示触发的具体规则。
  • 人工修正（蓝）：仅半小时明细行使用；该槽用能量为人工修正值；点击标签打开留痕详情（操作人 / 操作时间 / 原值 / 新值 / 原因）；人工值锁定，自动重算不覆盖。清单 / 汇总 / 时天月 rollup 行统一用「完整 / 异常」，不再单独展示「含人工修正」。
  • 空态：所选表具当日无任何明细时显示「暂无数据」；加载中：表格骨架屏。

边界与异常 v2.5 需求文档

关联模块：人工修正弹窗 — 五条护栏（§6.3）

  • 采集原始累计值不可改（审计源头）；修正只作用于派生的表具半小时明细。
  • 每次修正留痕：操作人 / 时间 / 原值 / 新值 / 原因（选填，空则记「—」），并打「人工修正」标记（区别于正常 / 坏值）。

按时间范围重算
交互说明 v2.5 需求文档

关联模块：按时间范围重算弹窗；入口：工具栏「按时间范围重算」按钮

  • 重算内容（不区分类型）：一次提交同时完成两步——① 能耗明细核算：按补全后的相邻尾值逐槽重算差值与数据质量标记（含时 / 天 / 月汇总联动重刷）；② 成本明细重刷：对同一区间按【当时生效计费方案】重算表具成本。能耗变化会影响成本，因此两项一起重算。
  • 时间范围：开始 / 结束日期，作用于当前所选表具与能源类型；提交后异步执行，完成后刷新列表。
  • 确认提交前时间范围须完整且开始不晚于结束，否则提交拦截并提示。
数据逻辑 v2.5 需求文档

关联模块：按时间范围重算弹窗 — 重算口径（§5.4 / §6.1 / §8.2 / §8.3）

  • 幂等覆盖：按幂等键「表具 + 能源类型 + 时间槽」覆盖写入，重复重算结果一致。
  • 范围含缺口紧邻下一槽：能耗明细核算自动把缺口紧邻的下一槽纳入范围（其减基准被补回），首槽读缺口前一槽尾值作基准。
  • 尊重人工修正：重算不覆盖已打「人工修正」标记的槽（人工值锁定），冲突提示人工复核。
  • 成本口径：成本明细在能耗核算完成后对同一区间重刷：成本 = 用能量 × 目标时间窗【当时生效计费方案】单价并归档；历史计费方案锁定不可改、只能新增未来版本，因此重算不改写历史电价；典型触发：断点续传 / 晚到补传、历史用能量被人工修正、表具晚应用 / 新应用计费方案补算此前无成本区间（未应用方案的表具本次仅完成能耗核算，成本待应用方案后再触发）。
  • 对象侧无需单独重算：表具成本更新后，对象成本下次 on-read 查询经 SUM 自动一致。
