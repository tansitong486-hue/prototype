沿用现网全局寻优对照表，标题为「当前控制策略前后对比」：按设备分类列出开机设备与控制参数，寻优前=触发时刻现场截面，寻优后=本轮正式结果。参数来源（柔性 / 回落 L1）在上方结论条以标签标注，本表表头不再重复。无正式结果时寻优后为空，只保留能读到的实际值。本页不加仿真对比。

数据逻辑 v2.8 需求文档

关联模块：未来 24 小时规划

一块里看：汇总卡（预计总电量 / 组合变更次数，开启电费才出预计总电费）、开机组合色带、三张预测图卡。电量与电费卡片数值下方展示与过去 24 小时的对比：过去 24h 指规划窗口前移一天的实际累计（电量来自计量，电费按当时电价累计），下降为绿色「↓ 省 xxx（x%）」、上升为橙色「↑ 增 xxx（x%）」，悬停显示口径说明。该对比同时受负荷与气象变化影响，定位是给用户的体感参考，不作为策略收益审计口径（严格收益仍走节能分析）。色带按开机组合分段，模式图例在色带卡右上角；同一模式下不同组合用同色系深浅区分（同一组合全程同色），组合变更点在色带上打点。时段标注为端点不含式（如「23:00–次日08:00 · 9h」，指 23:00 起至次日 08:00 前）；换组合走法未做成时，原候选切换点以 ⊘ 虚线锚点标在色带上，悬停显示未采纳原因。图卡一为总电功率 / 制冷能效 / 电费 Tab 切换（默认功率）；「电费」Tab 仅开启按电费寻优且取到电价时出现，柱图展示逐时预计电费并叠加峰平谷电价背景带（峰平谷图例随该 Tab 显示），悬停显示该小时电价（两个半小时均价）；图卡二冷量、图卡三湿球。三图与色带共用同一规划窗口时间轴且各自显示 x 轴，悬停联动。图上实线=实际值、虚线=预测值（电费 Tab 为深浅两色柱）；当前轮仅首时段有实际值，查历史轮次按当时已落小时补线。尾部预测不进本区。

字段说明 v2.8 现网对照

关联模块：寻优明细

沿用现网样式：左侧固定「分类 / 参数名称」，其后每个小时一组「实际值 / 预测值」；首行置信度跨两列；右侧滑条左右拖动看后续小时。首时段列淡蓝高亮并标「正式」，即本轮正式结果，其后各列为规划参考。「水冷冷水系统」分类下新增「模式」行（压缩制冷 / 自然冷 / 混合冷，实际列只在已落小时有值）；开启按电费寻优时该分类再增两行：电价（该小时两个半小时均价，跨实际 / 预测两列）、预计电费（预测=预测功率×电价，实际列在已落小时=实际功率×电价），关闭电费或未取到电价时这两行不出现。缺桶回落小时在小时表头加「复算」角标：该小时预测落到策略库没有的工况桶，按邻近桶同组合参数单步复算取值，悬停角标可看命中桶与回落依据（邻近桶的组合与参数可在工况策略库查到）；查表小时不加标记。尾部预测不进表。

数据逻辑 v2.8 需求文档

关联模块：工况策略库 Tab

「工况策略库」是 L1 策略先验表的页面名称：按工况桶（末端负荷向上取整 100 kW × 湿球向下取整 1 ℃）预先算好各候选开机组合的最优控制参数与功率，滚动规划逐小时查这张库。本 Tab 展示库的整体内容，与任何一轮寻优记录解耦：列表列出库内全部工况桶（含近期预测未命中的历史桶），按负荷、湿球升序排列，不展示「本轮命中 / 覆盖时段」等单轮信息，也不随寻优记录时间条翻历史轮。每行给出候选组合统计（可行 / 不合规）、桶内最优组合与功率、更新时间（该桶最近一次被计算覆盖的时间；三条件——机理模型 / 安全边界 / 寻优策略——未变且桶已在库内则凌晨检查跳过、时间不变）；库就绪后各桶均已可用，不再单列状态。白天预测漂出的库外新桶不进本列表，按邻近桶回落复算，解释见寻优明细的「复算」角标；库生产绑定的版本与评估证据走结果归档追溯，不上页面。

桶内胜者 ≠ 路线该小时组合：路线还受最短保持时长与切换准入校验约束。例如「换组合未做成」场景里，夜间桶内自然冷仍是表内最优，但准入校验（含湿球余量）不过，路线维持压缩制冷——解释见色带 ⊘ 锚点；非胜者组合行也必须保存，供路线在保持约束下停留时计价。

交互说明 v2.8 产品推断

关联模块：工况策略库 Tab — 操作

本 Tab 为纯只读展示，无任何操作入口：库的生产由系统自动触发（首次开启立即生产、其后每天凌晨检查），页面不提供手动补跑。唯一交互是点「展开」查看该桶每组合明细：候选组合 / 制冷模式 / 组合内最优控制参数 / 最优功率 / COP / 状态与不合规原因，口径与 v2.4 全局寻优「本轮搜索结果」一致；再点「收起」或同行可折叠。首次开启（库为空）时列表即本批待生产桶：顶部提示生产进度，更新时间列显示计算中 / 队列位次（按「未来最近的先算」排队），此时 L2 不滚动、结论条为「无正式结果」；未算完的行不可展开。面向对象以用户-运维与内部（算法 / 实施）为主。
