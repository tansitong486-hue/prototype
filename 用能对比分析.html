数据逻辑 v2.5 需求文档

关联模块：对比指标目录与对比结果取数口径

  • 指标目录：来自指标工厂首版清单——能耗指标（电能消耗量 / 用水量）、成本指标（电费总额 / 水费（统一价））、能效指标（PUE / CLF / PLF / OLF / WUE）。指标名称与单位沿用能效视图「指标列表」同一份口径，能源类型固化进指标名称，不另立命名；能耗 / 成本类按对象已启用计量的能源类型展开，未启用的能源类型不出现。
  • 取数口径：每个单元格 = 该对象在该时间段的指标跨度查询结果（起止 = 时间段起止）：能耗 / 成本为区间累计，能效为区间比值（分子 / 分母各自区间累计后再比）。历史区间读指标工厂物化统计分片，页面不暴露时间粒度概念，不在前端重算电价或能效，不直读原始累计量或旧统计表。
  • 成本口径：成本金额 = 表具核算明细成本金额沿当前计量拓扑归集（输出侧作减项），单位为元；未应用计费方案的对象在成本指标下无结果、不可选。
  • 对象可选性：只有当前指标有结果（有值）的对象可勾选参与对比；不可选的三类原因悬停可见——① 指标未注册到该对象类型（如楼栋查 PUE）；② 未启用对应能源计量；③ 有注册但算不出（待配置：缺系统对象电量输入；或成本指标未应用计费方案）。
  • 「—」语义：可选对象均有结果，「—」仅出现在个别时间段无数据时，悬停提示「所选时间段暂无数据」。
  • 数值格式：单位与小数位随指标——能耗整数（kWh / m³ 一位小数）、成本 2 位小数（元）、PUE / CLF / PLF / OLF 3 位小数（无量纲）、WUE 2 位小数（L/kWh）；柱状图 Y 轴刻度随指标量级自动保留小数。
  • 本期不进对比页：A3 分时成本（尖 / 峰 / 平 / 谷时电费，分时构成语义由总览看板能耗成本卡承接）；C1 实时能耗值（仅实时语义，无时间段对比意义）；风险评估类指标（指标工厂暂无风险类真源，沉淀需求池待注册后复核）。
  • 完整性：坏值 / 缺失槽仍不参与聚合、不作 0；本页不展示「含异常/缺失」角标（表格 / 柱状图均不出现），完整性提示由总览看板等承接。
交互说明 v2.5 需求文档

关联模块：左栏「对比指标」选择、对象树勾选与结果导出

  • 指标单选：「对比指标」下拉分能耗 / 成本 / 能效三组，一次只对比一个指标，默认「电能消耗量」；切换指标即整体刷新单位、图表与表格，对象勾选与时间段筛选保持不变（无结果对象除外）。
  • 对象可选性：切换指标后按「该对象是否有该指标结果」刷新对象树——PUE / WUE 仅园区 / 数据中心；CLF / PLF / OLF 为园区 / 数据中心及对应系统对象（暖通空调 / 电力 / 其他系统）；能耗 / 成本类按对象是否启用该能源计量、成本另要求已应用计费方案。无结果对象不可勾选，已勾选的自动取消勾选。
  • 对象树：始终展示对象全集（不做「仅有值」过滤），园区 / 数据中心 / 系统 / 楼栋全层级均可勾选参与对比；无结果对象置灰、悬停展示原因（未注册 / 未启用计量 / 待配置 / 未应用计费方案）。左侧箭头仅负责展开 / 收起，不影响勾选；上级对象与其下级对象可同时入选（各自独立取指标值）。
  • 时间段选择：单行排布——「+ 添加时间段」按钮与各时间段同行（对齐存量页面），上限 3 组，超出即时提示。
  • 柱状图：分组柱状图（与能耗流向分析 / 节能分析同一图表方案）——X 轴为对比对象、系列为时间段；悬停显示该对象各时间段数值（空值显示「—」）、柱顶常显数值标签；图表标题带当前指标名，Y 轴标注单位。
  • 表格视图：列结构 = 对比对象 + 对比指标（名称 + 单位，如「电能消耗量（kWh）」）+ 各时间段跨度值，切换指标后「对比指标」列同步刷新。
  • 导出：右上角「导出」输出当前对比表格，列结构与页面表格一致（对比对象 + 对比指标 + 各时间段，「—」原样导出）；未勾选对象时点击导出给出提示。
  • 上限：对比对象最多 5 个，超出即时提示。
