数据逻辑 v2.5 需求文档

关联模块：整页 — 对象树与计量拓扑的关系

  • 对象树即计量对象树：本页左侧对象树（工程 / 项目 / 系统 / 集合 / 设备）就是能耗计量的对象范围；计量拓扑的产物是「能源类型 × 当前对象 ↔ 下级对象 / 表具」且每条关系带计量方向（输入 / 输出）；对象能耗 / 成本 / 能效指标由指标工厂按同一张拓扑物化。
  • 两个配置入口、一份数据：单对象配置在本页「能效配置」Tab 点「配置」进弹窗完成，跨对象批量作业（多视图树、Excel 全局导入导出）仍在《能源计量关系》；两处写同一份「能耗计量」关系对象、共用同一套图约束校验，不存在两套口径。
  • 归属唯一：查重键为「表具（含组件）+ 能源类型」——同一能源类型下一块表具只能挂到一个计量关系上，不按输入 / 输出拆分名额；计量方向只决定计算符号。重复占用在两个配置入口都强制拦截。
  • 历史随当前拓扑（产品已接受口径）：对象查询始终沿【当前】计量拓扑聚合；表具改绑计量对象后，其全部历史能耗 / 成本随之归到新对象名下、旧对象对应减少。本期不做计量拓扑生效版本。

关联模块：指标列表 — 实施核数与计算链路排查

  • 实时指标：不提供能源类型筛选。默认「仅有值」：只展示当前对象能算出结果的能源瞬时值；可切换「全部」查看适用指标全集，算不出的显示「待配置」，便于区分计量未配 / 测点缺值。PUE / CLF / PLF / OLF / WUE 仅在「园区」「数据中心单元」实例上适用。实时值只查当前、不落历史。操作列提供「曲线」，交互对齐测点列表。
  • 时间段指标：查询区只有起止时间。能源类型、计费时段固化进指标名称；显隐同样受「仅有值 / 全部」开关控制。无分时能源仅展示一条「费用（统一价）」。时间段指标不提供曲线入口。
  • 计算排查：点击「计算口径」中的绿色表达式打开只读预览。拓扑展示指标定义及本次查询解析到的对象指标、表具核算明细或瞬时量测点；点选节点后，右侧展示其引用 ID / 属性、当前结果、下级节点和异常原因。页面不提供表达式编辑。
  • 业务分类：列表展示「业务分类」列，筛选区提供业务分类选择器（默认「全部」）。本期指标（实时 / 时间段的能耗、成本、能效比值等）均归属「能效」；选其他分类时列表为空。后续扩展容量等分类时只增指标定义，不另开专用页面。
  • 扩展规则：列表与弹窗均按通用指标定义和计算节点渲染。新增能源、计费时段或能效指标时只增加指标定义及节点数据，不新增专用列或专用页面。

交互说明 v2.5 需求文档

关联模块：能效配置 Tab — 配置项清单（一行一个配置项，点「配置」进弹窗）

  • 页面形态（后续可扩展）：本 Tab 是当前对象的配置项清单，每个配置能力只占一行：左侧配置项名称 + 当前配置摘要，右侧「配置」。所有具体操作都在各自弹窗里完成，本 Tab 不就地展开表单，后续新增配置模块按行追加即可。
  • 本期两行：「能源计量关系」（摘要为各能源已配置条数，未配置显示「未配置」）、「用能定额考核」。
  • 行内摘要来源：读当前对象的实际配置数据实时生成，弹窗内改完关闭即刷新；切换左树对象时整个清单按新对象重算。
  • 两个入口一份数据：本 Tab 的弹窗只配当前对象，《能源计量关系》做跨对象批量作业；两处写的是同一份「能耗计量」关系对象、共用同一套校验，任一处改动对另一处立即可见。
  • 弹窗里不做的：多视图（空间 / 容量）树切换、Excel 全局导入导出、跨对象批量改方向或批量删除——这些仍只在《能源计量关系》，弹窗头部提供跳转。
  • 用能定额考核：沿用原入口；当前对象在任一能源下都还没有计量关系时，定额保存不可用——可直接在上一行的计量关系弹窗补配，不必先跳走。
数据逻辑 v2.5 需求文档

关联模块：能效配置 Tab — 配置项摘要与单对象计量关系口径

  • 行内摘要口径：「能源计量关系」行按能源类型列出条数（如「电 3 条 · 水 2 条」，只列有关系的能源），一条都没有时显示「未配置」；摘要只统计当前对象的直接成员，不含下级对象自己的关系。
  • 产物形态：「计量对象 × 能源类型 × 成员 × 计量方向」，与《能源计量关系》完全一致；同一对象在各能源下各有一套独立拓扑，禁止跨能源混配、混算。
  • 作用范围：关系表只列当前对象在当前能源下的直接成员；下级对象的下级不在本表展开，需选中该下级对象后再看（计算侧仍递归整棵子树）。
  • 类型只有两种：表具、下级对象。组件属于表具之下，名称列用「所属表具」标明，类型仍记「表具」。
  • 表具池随能源过滤：只列当前能源下的表具 / 组件（电表不出现在「水」Tab）；默认只看未计量，可切已计量 / 全部；支持空间位置树（选父含子）与搜索，上千条时分页（每页 20）。
  • 归属唯一：查重键为「表具（含组件）+ 能源类型」——同一能源下一块表具只能挂一次，不按输入 / 输出拆名额；已被占用的表具在池中标「已计量」且不可拖，冲突行在关系表内标红提示。
  • 今日试算口径：沿当前能源拓扑递归到叶子表具，输入记 +1、输出记 −1，同一叶子多路径系数相加后与今日用量相乘汇总；单位取该能源在《能源配置》中的累计量单位。
  • 原型说明：本页与《能源计量关系》各自维护演示数据，页面间状态不互通；真实系统是同一份关系对象。

关联模块：「能源计量关系配置」弹窗 — 只配当前对象，交互对齐《能源计量关系》全量页

  • 配置对象固定：标题栏显示当前对象名称与物模型，弹窗内的一切操作都作用于该对象；要换对象请关闭弹窗后在左树重选。
  • 能源类型 Tab：选项跟随《能源配置》能源类型主数据动态生成（非本页写死），默认选中第一个；角标为当前对象在该能源下的关系条数，0 条表示该能源尚未配置。切换后关系表、对象树配置态、表具池、今日试算一起按该能源重绘。
  • 加关系（两种拖拽，与全量页一致）：从左栏对象树拖节点进关系表 = 加「下级对象」；从右栏表具池拖表具 / 组件进关系表 = 加「表具」。默认方向为输入。
  • 左栏对象树：只作拖拽来源，点击不切换配置对象；当前对象标「当前对象」且不可拖，已加为成员的节点置灰不可重复拖入，节点前的绿点表示该对象在当前能源下已有关系；支持按名称搜索。
  • 改方向 / 删除：点方向开关在输入 / 输出间切换，点「删除」移除该行；变更即时生效，弹窗底部只有「完成」，不存在「保存 / 取消」的暂存语义。
  • 今日试算：点「今日试算」按当前能源拓扑递归展开到叶子表具重算有符号用量，可跳《表具能耗明细》核对。
  • 关闭后：「能效配置」Tab 内该行摘要按最新关系条数刷新。
