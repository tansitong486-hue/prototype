视图部分 — 视图切换（左树顶部，与节点-测点树完全一致的三项）
  • 现状：本弹窗只有空间树、没有视图切换器；而原始数据查询 / 运行极值查询 / 融合组态三处的节点-测点树已支持空间 / 容量 / 能效三视图。本需求是把弹窗对齐到已有能力，不新造视图数据源。
  • 三视图是同一批物模型实例的不同树结构，节点可跨视图复用。因此切换视图不清空已选清单，用户可在空间视图选几个、切到能效视图再选几个。
  • 已选清单按「实例 + 类型 + 标识」去重，同一实例的同一数据项在不同视图重复勾选只保留一条。
  • 未配置的视图在下拉中置灰并提示先配置视图，不隐藏。
指标部分 — 指标叶子（树上挂载规则）
  • 指标绑定在对象实例上（园区 / 数据中心 / 系统 / 设备组 / 设备），不挂在组件或测点下。指标叶子直接挂在对象节点下，与设备子节点同级同层——不套「指标（N）」分组节点、不新增层级，仅靠图标与类型标签区别于测点。
  • 某对象下出现哪些指标，由「该对象所属物模型（含继承链）上注册的指标」∩「按能源类型 / 计费时段展开的入参组合」决定，真源是物模型 × 指标注册矩阵。选择器不为具体对象类型写死分支——新增对象类型或调整指标适用范围时选择器无需改造。
  • 能源类型与计费时段已固化进指标名称（「电能消耗量」「尖时电费」），所以勾中即已确定入参，不需要二次参数面板。
  • 按实例添加不提供「仅有值 / 全部」与业务分类筛选：默认只展示算得出结果的指标（仅有值）；缺输入的指标不出现在树上。

视图部分 — 三栏语义调整
  • 第一栏：「选择空间」→「选择对象范围」，新增三视图切换。范围解析按当前视图子树递归（含下下级），不只取直接一层子节点。

指标部分 — 按物模型批量添加指标
  • 选定范围 + 物模型 + 指标后，一次性加入该范围内所有该模型（含继承子模型）实例的同一指标，与现有「某模型所有实例的对应测点」完全对称。这是明细引擎册「模板化绑定（绑 (物模型, 指标)，切换实例即复用）」在报表侧的落点。
  • 可选指标列表 = 该物模型上注册的指标（取指标选取服务的「按物模型列指标」接口）。
  • 按模型添加不提供「仅有值 / 全部」开关：第三栏默认展示该物模型上注册的全部指标（含待配置），便于按类型批量勾选。
红线：只批量添加，不产出模型级合计值
批量添加得到的是「N 个实例 × 同一指标」的 N 条独立数据项，不是该模型全部实例的合计或平均。原因：同一块表具可能同时落在多个实例的计量拓扑内，跨实例合计会绕开叶子系数与重复路径校验形成重复计量。横向汇总由用户在报表内自行处理。

指标部分 — 参数查询 / 查询方案配置的语义收敛
  • 时段类型指标是按粒度预聚合的结果，不是采样序列。采样周期只开放 1 小时及以上（半小时及更细档位对时段指标不可选）。
  • 时段指标不新增聚合类型，复用现有 「求和」：选「求和」时有值；选平均 / 最大 / 最小等时该列为空值「—」。
  • 实时类型指标本页可选：采样周期与聚合方式与测点一致（全部档位均可）；数据需经查询、计算后呈现。
  • 混选测点 + 时段指标时，聚合方式控件不做限制（求和 / 平均 / 最大 / 最小等依然都可选）。测点 / 实时指标按所选聚合方式正常出数；时段指标仅在「求和」下有值，其余聚合方式结果为「—」，不拦截查询、不置灰选项。
  • 查询方案配置：方案需连带保存指标的粒度与聚合方式，加载时完整复原；仅含测点的历史方案保持原样可用，不做数据迁移；加载时校验引用有效性，指标被停用 / 删除时标记失效并提示具体缺失项，不静默丢项。
