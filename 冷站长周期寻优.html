版本信息

当前版本：v2.0

更新日期：2026-05-08

主要变化（v2.0）：适配风冷冷水系统：规则配置中的设备数量寻优规则、模拟量寻优规则、投入/投出配置均隐藏冷却侧设备及参数（板换 / 冷却水泵 / 冷却塔 / 冷却水温度等）；环境变量与寻优明细展示「室外干球温度」，不再沿用水冷冷水系统的「室外湿球温度」展示口径。

主要变化（v1.8）：规则配置弹窗对齐「冷站全局寻优」最新版本——寻优规划配置 Tab 包含：天气预报城市、预测步长（每小时 / 每 2 / 4 / 6 小时，默认每 2 小时）、仿真模型、安全边界、寻优器（L-SHADE / SLSQP，切换后参数联动）、种群初始化数量、种群最终数量、最大迭代数；设备数量寻优规则表（水冷冷水机组 / 板式换热器 / 冷冻水泵 / 冷却水泵 / 冷却塔）；模拟量寻优规则表（步长 + 默认值）；新增「寻优目标偏好」三个滑块（安全余量偏好 λ₁、设备切换容忍度 λ₂、参数平稳偏好 λ₃），长周期寻优涉及设备启停时序规划，λ₂ 本页可用（柔性寻优页置灰）；λ₃ 长周期各时段独立求解不涉及时序平稳性，本页置灰不可用（柔性寻优页可调）；投入/投出配置 Tab 与全局寻优保持一致。

历史版本（v1.0）：由古典 Axure「冷站长周期寻优」迁移至 AI 原型；含环境变量预测图、系统能效趋势图、寻优明细结构化表；规则配置为简单文字占位弹窗。

需求说明

关联模块：冷站长周期寻优规则配置 —「寻优目标偏好」（v1.8 新增）

多目标加权寻优配置，对应目标函数 J = P_norm + λ₁·C_safety + λ₂·C_switch + λ₃·C_swing。

  • 安全余量偏好（λ₁）：0.00～0.50，默认 0.10；越大寻优结果越远离安全硬边界。
  • 设备切换容忍度（λ₂）：0.00～0.50，默认 0.15；长周期寻优涉及设备启停时序规划，本页可用（柔性寻优页置灰）。
  • 参数平稳偏好（λ₃）：0.00～0.30，默认 0.05；长周期各时段独立求解，不涉及时序平稳性，本页置灰不可用，默认 0（柔性寻优页可调）。

三项权重均为 0 时行为与原单目标最小功率等价（向下兼容）。
