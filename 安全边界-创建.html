变更概述：v2.9 廊坊群控下发兼容（需求 3）——安全边界支持群控系统设定点（标准功能，后续 BA 群控项目复用）。BA 设定点是群控系统设备（示例「A路水冷群控系统」，设备类型「水冷群控系统」）上的平级测点，不分组；在水冷类型「模拟控制变量边界配置」表上方点「添加群控设定点」→ 选群控实例 → 平铺勾选设定点 → 加入后在同一张边界表里和其他设备一样显示（对象列为群控系统设备，变量名称为测点名称），逐点配硬 / 软上下限。

本页改了什么：①边界表上方新增「添加群控设定点」入口和选择弹窗；②群控设定点作为一个设备追加在原边界表末尾，列、样式与原有设备行完全一致（不加分段、不加操作列）；③保存时校验群控设定点软边界。冷站设备变量、被控变量、设备数量和末端机房配置均不变。

用途：群控设定点的边界只给转写引擎贴边和手动下发弹窗校验，不参与仿真结果的安全校验。示例为廊坊 A 路「A路水冷群控系统」的 58 个设定点（安全边界对象选「1号冷站 / 冷水系统 A（水冷）」时可添加）。

依据：《廊坊群控设定点转写与下发需求文档》§七、§十四 第 1 项。

关联模块：模拟控制变量边界配置 — 群控系统设定点（生效口径）

  • 生效口径与现有一致：软边界优先；软边界未填回落硬边界；没添加进来的设定点不约束。

字段说明 v2.8 需求文档

关联模块：模拟控制变量边界配置（末端机房）— 风机转速下限 / 上限设定

变量名称：「风机转速下限设定」「风机转速上限设定」，挂精密空调本体，不再写【风机1】。水冷 / 风冷 DX 都出这两行。

单位：%

硬边界：只读，来自物模型 / 设备极限，演示为 10～100。

软边界：用户可编；创建时空着。约束：硬下 ≤ 软下 ≤ 软上 ≤ 硬上。

给柔性用：夹边取软边界；未填则回落硬边界。风机转速上限作为风冷 DX 的辅助通道，按通道温度裕度每轮走一个步长，目标夹在软下限～软上限之间；掺混且叫不醒 / 疑似故障 / 故障位报警时一轮直接压到软下限，所以启用风冷辅助时软下限必填，取厂家允许的最低连续运行风量。

字段说明 v2.8 需求文档

关联模块：模拟控制变量边界配置（末端机房）— 送风温度设定 / 回风温度设定

两层用途：一是控制变量本身的裁剪边界（主控制变量选了哪一行，柔性目标就夹在该行软边界内，未填回落硬边界）；二是「送风温度设定」行不论主变量选的是送风还是回风，都作为该机实测送风温度的门控：实测送风 ≥ 软上限 → 本轮不省电（再高制冷不足）；湿度缺失、无法算露点时，实测送风 ≤ 软下限 → 本轮不增冷。这替代了此前算法内置的 24℃ / 17℃ 全局常数，高温设计机房（送风 25～26℃）不再被写死的 24℃ 卡住。

回风温度设定 · 下限：掺混机组叫醒时目标为「回风 − 启动温差」，若低于本行软下限则输出软下限并告警「无法叫醒压缩机，请放开下限或关停」；实施在核对下限时要留出叫醒空间。

校验：硬下 ≤ 软下 ≤ 软上 ≤ 硬上，同页既有规则。

交互说明 v2.9 产品推断

关联模块：「添加群控设定点」弹窗；入口：模拟控制变量边界配置表格右上「+ 添加群控设定点」按钮

  • 顺序：先选群控实例，再勾选设定点；未选实例时设定点区显示「请先选择群控实例」。切换实例会清空本次勾选。
  • 勾选：设定点平铺展示、不分组（与设备上的测点一致）；支持顶部「全选」和单个勾选，右上角显示「共 N 个设定点」（已添加过的附「已添加 M 个」）。
  • 已添加的点：默认勾选并标「已添加」；取消勾选后点「确定」，即从边界表移除（不需要单独的删除按钮，边界表列与原表一致）。
  • 确定：勾选结果与当前已加入的不同时才可点；点击后关闭弹窗，边界表按勾选结果新增或移除设定点行（新增行的硬边界按物模型量程带出，软边界为空），toast 提示新增、移除的个数。群控实例只有一个时自动选中。
  • 取消 / 右上角关闭：关闭弹窗，不保留本次勾选。
