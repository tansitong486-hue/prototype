数据逻辑 v2.5 需求文档

关联模块：整页 — 对象树与计量拓扑的关系

  • 对象树即计量对象树：本页左侧对象树（工程 / 项目 / 系统 / 集合 / 设备）就是能耗计量的对象范围；「能耗计量方案」配置的产物是一棵计量拓扑（当前对象 ↔ 下级对象 / 表具），对象的能耗与成本查询时沿该拓扑对表具归档明细做 on-read 聚合（SUM），对象层不单独归档。
  • 表具归属唯一：一块表具只能归属一个计量对象，不得同时挂到两处拓扑；计量方案配置层强制查重（「选择应用范围」弹窗内已被占用的表具置灰不可选），从源头杜绝重复计量。
  • 历史随当前拓扑（产品已接受口径）：对象查询始终沿【当前】计量拓扑聚合；表具改绑计量对象后，其全部历史能耗 / 成本随之归到新对象名下、旧对象对应减少。本期不做计量拓扑生效版本。

字段说明 v2.5 引用自古典原型

关联模块：「能耗计量方案配置」弹窗（入口：能效配置 Tab → 能耗计量方案 → 配置）

  • 计量的能源：行按「能源计费配置 → 能源类型」动态生成（当前环境为冷量 / 水 / 电），每行独立配置。
  • 计量规则：单选、非必选，未选择表示当前节点下无此能源介质的能耗计量。选项两个： 仪表计量能耗（由所选表具直接计量，选中后行内出现「计量对象选择(已选N个)」按钮，再次配置回显已选数量）； 各子节点计量能耗（由下级节点汇总，选中后行内出现子节点多选：仅可选下一级节点，且须为已启用对应能源计量方案的节点；子节点新增 / 删除时所选范围需联动调整）。
  • 启用开关：默认关闭。开启后该能源的计量方案生效，并在总览看板对应对象上自动勾选该能源类型的「能耗趋势」「能耗成本」图表；关闭则自动取消勾选。
  • 保存：校验通过后保存当前节点计量方案并生成 / 更新计量拓扑；保存时对表具归属强制查重（表具归属唯一）。
