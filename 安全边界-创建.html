版本信息

当前版本：v2.0

更新日期：2026-04-29

变更概述：设备数量边界配置支持动态扩展：当所选安全边界对象（水冷冷水系统）下不含冷却塔和冷却泵时（即风冷冷水系统场景），自动隐藏"冷却塔数量"和"冷却泵数量"两个配置项；安全边界对象下拉新增风冷系统模拟选项。

历史：v1.8（2026-04-13）—— 按真实系统 UI 重构创建安全边界页面；取消步骤式布局，改为可折叠卡片分区；新增面包屑导航和返回箭头；类型切换联动三个配置区；变量边界表格统一为 7 列（含软边界）。

本页说明：创建安全边界的表单页，从列表页"创建安全边界"按钮进入。选择安全边界类型后，下方设备数量、模拟控制变量、被控变量三个配置区随类型动态切换展示内容；水冷类型下，配置项还会根据所选对象是否含冷却侧设备进一步动态显隐。

版本信息 v2.8

v2.8（2026-09-01）：末端机房「模拟控制变量边界配置」中，风机转速下限设定 / 上限设定改为挂在精密空调本体，不再写【风机1】。水冷 / 风冷 DX 都继承该本体，有对象就出这两行。7 列、软硬约束、用户只改软边界，与送风 / 回风同一套。柔性寻优夹边取软边界，未填回落硬边界。

字段说明 v2.8 需求文档

关联模块：模拟控制变量边界配置（末端机房）— 风机转速下限 / 上限设定

变量名称：「风机转速下限设定」「风机转速上限设定」，挂精密空调本体，不再写【风机1】。水冷 / 风冷 DX 都出这两行。

单位：%

硬边界：只读，来自物模型 / 设备极限，演示为 10～100。

软边界：用户可编；创建时空着。约束：硬下 ≤ 软下 ≤ 软上 ≤ 硬上。

给柔性用：夹边取软边界；未填则回落硬边界。打开风冷辅助后，算出的机房带子再按这两行逐台夹边。
