字段说明v3.0需求文档 ·《冷站配置需求文档》§6.2、附录 B

关联模块：填写规则

  • 只处理标「是」的行；生成要求是自然语言意图，自定义表达式填写最终可解析写法。
  • 允许常数、完整测点 ID（含组件后缀 #1）、四则运算与括号、比较 > >= < <= == !=、三元条件、&& / ||、sum / avg / max / min / count。
  • 汇总示例：sum(0_84_1_100_0, 0_85_1_100_0)；比值须除零保护，完整示例见填写说明。
  • 禁止内部引用格式、自然语言、不完整或编造的测点 ID；示例 ID 仅为格式样例。
  • 给大模型：只改自定义表达式、表达式备注，只引用文件中完整 ID；无法判断则留空并注明原因。
查看填写规则
  • 只处理标「是」的行；在「自定义表达式」中填写最终写法。
  • 可用常数、完整测点编号、加减乘除、括号、条件判断和汇总函数。
  • 条件写法示例：(0_84_1_104_0 > 20) ? 1 : 0；比值须先判断分母是否为 0。
  • 不要写自然语言、内部引用格式、不完整或编造的测点编号；无法判断时留空并填写备注。
