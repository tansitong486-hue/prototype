需求说明 v2.4 需求文档

关联模块：多工况探索 — 策略制定（阶段一）

「多工况探索」是 v2.4 新增的独立功能模块，目标是在受控、安全前提下主动驱动冷站走到被动运行走不到的稀缺工况，为模型训练补充样本。模块内分三阶段：策略制定（本页，离线编排，不下发不动设备）→执行（按排程连续下发 + 判稳后归档）→验证（对归档探索点用重训后模型重算预测 vs 归档实测，不入库）。策略归属创建时选定的目标系统（本页演示：3#数据中心水冷冷水系统），本页只读展示。

本页覆盖：开机组合；绑定安全边界 / 仿真实例 / 探索下发策略（允许手动或自动）/ 安全回退策略；基准线录入与边界校验；补偿步长 + 排程间隔时长生成排程；历史已覆盖点灰显保留可勾回；冷却塔批次 batch_guard；审核勾选后从本页发起执行。

两套下发勿混：寻优下发策略（柔性/全局）在探索执行期须为「手动」；本页绑定的是探索下发策略，允许「手动」或「自动」，只控制本模块排程如何推进。

本期不覆盖：设备开关机 / 加减机探索；基准线自动求解；执行下发与判稳归档（见执行详情页）；验证详情展示（见验证详情页）。

  • 行来源：表格行 = ①中已勾选开机设备涉及的设备类型，按类型一行；控制测点 / 反馈测点有标准物模型默认值，可改选；不按设备实例逐台生成行；每行"应用实例"说明随①区勾选联动刷新。

数据逻辑 v2.4 需求文档

关联模块：历史回溯与间隔写入（需求 7.3 / 7.4）

  • 邻域窗口：目标值 v ± 半个调整步长；窗口内稳态样本 n ≥ 20 → 已覆盖（灰显、默认不勾选、可勾回）；n < 20 → 空白/稀疏（默认勾选）。

  • 已覆盖点不从清单消失，仅灰显且默认不勾选。

关联模块：④ 执行计划清单

  • 全选 / 清空勾选：草稿态可用；全选会勾上已覆盖灰显行（强制勾回）。

  • 发起执行：校验已绑四项（边界/仿真/下发/回退）+ 至少勾选 1 点；就绪后跳转 多工况探索-执行详情.html?ready=1。
数据逻辑 v2.4 需求文档

关联模块：④ 汇总条

「共 N 步」= 清单总行数（含已覆盖灰显）；「含已覆盖灰显 M 点」= hist_covered=true 的行数（默认不勾选可强制勾回）；「预计总时长 / 拟执行 K 步」= 当前已勾选行的 est_duration 累加，随勾选变化。进入执行中后排程才锁定。

边界与异常 v2.4 需求文档

关联模块：④ 执行计划清单

  • 未绑齐四项或无勾选点 → 「发起执行」置灰。
  • 草稿态改间隔 / 下发 / 回退：写回策略主表；已开跑 run 仍用开跑快照。
  • 间隔须 > 0，否则生成/刷新等待条件时提示。
