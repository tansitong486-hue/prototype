版本信息 v2.5

当前版本：v2.5

更新日期：2026-08-25

版本价值目标：配得快——批量配好计量关系后，能耗、成本、能效的实时和累计指标自动出来，单项目实时配置一天内完成。

变更概述：页面名称为「能源拓扑配置」，同时维护能耗计量与供电两类拓扑：① 关系类型列改为只读标签，支持供电的列头柜 / 支路合并展示“能耗计量 + 供电”；② 新增支持供电的支路时自动创建两条独立底层关系，无二选一或切换；③ 合并行的输入 / 输出只更新能耗计量关系，删除成员一次移除该成员的两条关系；④ 历史单关系按实际标签展示，再次添加时补齐缺失关系；⑤ 今日试算与 Excel 仍只维护能耗计量关系；⑥ 中间栏在「拓扑关系列表」与「今日试算」之间新增「历史数据计算规则」：每个对象在当前能源下自选历史解释方式，选项 2 支持按日期范围用最新拓扑重算。

本页说明：本页用于跨对象配置能耗计量关系和供电关系。两类关系独立保存、独立校验；同一列头柜支路可以同时参与两类关系。页头能源 Tab、对象树、关系表和表具池按当前能源类型展示；今日试算只读取能耗计量关系。历史数据计算规则按「对象 × 当前能源」保存，不进 Excel。Excel 导入导出继续用于能耗计量关系。

需求说明 v2.5 需求文档

页面定位与范围（需求 3 / §4.4）：

  • 与《能效视图》的分工：本页面向实施的批量作业（跨对象连续配置、多视图树、Excel 全局导入导出）；单对象配置在《能效视图》「能效配置」Tab 的「能源拓扑配置」行点「配置」，在弹窗内完成。两处产物、校验规则一致，任一处改动对另一处立即可见。
  • 能源分域（核心）：主工作区不是「一套关系看全部能源」，而是「先选能源类型，再只看/只配该能源」。各能源拓扑彼此独立，禁止跨能源混配、混算。
  • 能源类型来源：页头 Tab 不在本页维护，跟随《能源配置》能源类型列表动态扩展（预置电/水/冷量的可删性等规则仍以《能源配置》为准；本页原型示意为当前三类）。
  • 主路径：选能源 Tab → 从视图树选择设备实例或组件实例 → 从表具池拖入对象或表具 → 在“关系类型”列查看只读标签。普通成员只建立“能耗计量”；支持供电的列头柜 / 支路自动同时建立“能耗计量”和“供电”，无需选择。
  • 左树「已配置/未配置」、中间拓扑关系列表、右侧表具池和今日试算均随当前能源 Tab 动态切换；表具池仅标识每个表具可配置的拓扑关系类型。
  • 今日试算按计量关系向下展开到实际表具后做有符号汇总（原型 mock）；按钮固定为「今日试算」，点击即重算。
  • 每个计量对象在当前能源下自选「历史数据计算规则」；默认沿用最新拓扑计算全部历史。选第二项后可按日期范围用当前最新拓扑重算该对象。

交互说明 v2.5 需求文档

关联模块：页头能源类型 Tab 与导入导出

  • Tab 选项来源：读取《能源配置》中的能源类型主数据动态生成（非本页写死）。系统预置电 / 水 / 冷量；在《能源配置》新增类型后，本页自动多出对应 Tab；删除后该 Tab 不再出现（删除约束见《能源配置》：预置三类不可删；已被计费方案等引用时不可删）。
  • 默认选中：进入页面时默认选中列表中的第一个能源类型（原型示意默认「电」）；同一时刻仅一个 Tab 激活。
  • 切换即刷新主工作区：点击任一能源 Tab 后，下方三栏（对象树配置态、计量关系表、表具池）与今日试算立即按该能源重绘，不保留上一能源的关系行/表具列表。
  • 选中对象保留：切换能源时尽量保留左树当前选中对象；中间表改为展示该对象在新能源下的直接关系（可能为空，属正常——表示该对象尚未配置该能源）。
  • 导入 / 导出：页头「导出」快捷下载当前配置；「导入」打开「用 Excel 更新计量关系」三段式弹窗（下载 → 上传 → 检查替换）。跨对象、跨能源，不绑定当前 Tab；Excel「能源类型」合法值以《能源配置》为准。
数据逻辑 v2.5 需求文档

关联模块：能源类型动态展示边界（整页主工作区；主数据来自《能源配置》）

  • 主数据依赖：能源类型名称、累计量单位、实时值单位、成对测点定义均在《能源配置》维护。本页只消费：Tab 列表 = 有效能源类型；试算/展示用量单位 = 该能源的累计量单位；表具池候选 = 命中该能源累积量测点定义的实例。
  • 分域键：所有配置读写、占用校验、试算展开都以「当前能源类型」为边界。产物形态为「计量对象 × 能源类型 × 成员 × 计量方向」；同一对象可按每个已配置能源各建一套拓扑，互不影响。
  • 左树配置态随能源变：● = 该实例在当前能源下已有 ≥1 条关系；○ = 当前能源尚未配置。设备实例与组件实例分别判定，切到另一能源时按该能源重新计算。
  • 组件实例：组件与设备实例使用相同的实例身份和关系规则；所属实例与层级路径仅用于展示。实例树父子层级不自动生成计量关系，也不自动继承或汇总。
  • 中间关系表随能源变：按成员合并列出当前对象 + 当前能源的关系，关系类型只读展示实际存在的标签；双关系成员一行展示“能耗计量 + 供电”，输入 / 输出只作用于其中的能耗计量关系。
  • 表具池随能源变：仅列出当前能源下的表具/组件，并标识可配置的“计量”“供电”拓扑关系类型；关联状态统一由“未关联 / 已关联”筛选表达。
  • 今日试算随能源变：按当前能源计量关系展开到实际表具；用量单位取该能源在《能源配置》中的累计量单位（预置示意：电/冷量 kWh，水 m³）。
  • 历史规则随能源变：「历史数据计算规则」按「当前对象 × 当前能源」读取，切 Tab 不串到另一能源。
  • 查重与校验范围：查重键为「表具（含组件）+ 能源类型」——同一表具可在不同能源各挂一次，但同一能源下只能挂一次。图约束也在「当前对象 × 当前能源」范围内执行。
  • 与导入导出的关系：Excel 文件内按「能源类型」列承载多能源数据，合法值须存在于《能源配置》；页面编辑态仍一次只操作一个 Tab，批量搬迁走全局导入导出。
交互说明 v2.5 需求文档

关联模块：多视图对象树 · 关系表 · 今日试算 · 表具池（均受上方当前能源约束）

  • 视图切换：空间 / 容量 / 能效三套树复用同一批实例 ID；设备实例下展示其组件实例，两类节点均可选择或拖入。视图切换不改变当前能源。
  • 配置态：● / ○ 只表示当前能源是否已有关系，不限制拖拽；未配置对象也可拖入关系表作为下级。
  • 组件角色：组件实例既可作为当前计量对象，也可作为下级计量对象；组件具备表具能力时还可作为叶子表具。三种角色均使用组件自身实例 ID，互不替代。
  • 关系类型：关系类型列只读，不提供选择或切换。普通成员新增后只显示“能耗计量”；支持供电的列头柜 / 支路新增后自动创建两条独立底层关系，并在同一行显示“能耗计量 + 供电”。历史只有一种关系时只显示实际标签，再次拖入可补齐缺失关系。
  • 表具池：筛选仅保留“未关联 / 已关联”，默认展示未关联；卡片固定两行，仅展示该表具可配置的拓扑关系类型，不重复显示关联状态说明。
  • 合并展示、独立存储：同一支路的两类关系在页面合并为一行，但底层仍是两条独立记录、独立生命周期。输入 / 输出只更新能耗计量记录；页面点击“删除”表示移除该成员，一次删除当前对象 / 能源下实际存在的全部关系。仅删除某一底层关系不属于本页交互。
  • 今日试算：结果区常显；点击「今日试算」按当前能源计量关系重算各表具有符号用量；可跳转表具能耗明细（带当前能源参数）。今日试算只验今天，不受历史规则影响。
  • 历史数据计算规则：跟当前对象、当前能源走。默认第一项；选第二项后标题右侧出现「重算」。未选对象时与试算一同禁用。

交互说明 v2.5 产品推断

关联模块：历史数据计算规则

  • 两个选项互斥，作用于当前对象 × 当前能源。未选对象时选项与「重算」禁用。
  • 默认第一项「沿用最新拓扑」。切到第二项后，标题右侧出现「重算」；再切回第一项须确认，确认后按当前拓扑重算该对象全部保留期历史。
  • 点「重算」打开日期弹窗。提交成功后提示已按当前最新拓扑重算所选日期（原型）。取消或关闭不改数据。
  • 今日试算仍只按今天 + 当前图预览，不读这条规则。
数据逻辑 v2.5 产品推断

关联模块：历史数据计算规则 — 对象指标如何解释历史拓扑

  • 规则只解释本对象的直接关系（挂了谁、输入/输出）。往下展开时，下级计量对象继续用下级自己的规则。
  • 第一项：该对象在该能源下的关系一保存，就用当前图重算它自己的全部保留期历史。不提供重算按钮。
  • 第二项：保存关系从保存时刻起用新图，已有历史按该对象当时的直接关系解释；不自动冲历史。
  • 第二项的重算：把所选日期内该对象的直接关系按重算当时的最新图解释并重算该对象该区间结果。下级各算各的，不自动改上级。该区间之后再改图也不会去动，除非再重算一次。
  • 只作用于能耗计量对象指标；供电、表具事实、计费事实不进这条规则。查询指标与实时历史必须跟同一套对象规则走。
  • Excel 导入导出不带本字段，避免表格误改政策。
边界与异常 v2.5 产品推断

关联模块：历史数据计算规则 — 切换与重算校验

  • 从第二项切回第一项：取消则留在第二项，不重算。
  • 重算日期必填；开始日期不能晚于结束日期；不能选未来日。校验失败时留在弹窗并提示原因。
  • 树上允许「上级已按新图、下级某段仍按旧图」，这是对象级规则的正常结果，不当异常。

交互说明 v2.5 需求文档

关联模块：页头「导入」→ 用 Excel 更新计量关系

  • 面向实施的三段式：① 下载当前配置 → ② 在 Excel 只改「关系清单」→ ③ 上传检查通过后整表替换。跨对象、跨能源；不绑定当前对象/能源 Tab。
  • 弹窗第 1 步提供「下载当前配置」（与页头「导出」同一文件）；已有文件可点「我已有文件，去上传」跳过下载。
  • 工作簿仍含 5 个 Sheet；只允许编辑 Sheet1「关系清单」。设备实例与组件实例均直接使用自身实例 ID；Sheet5 为能源表具对照（含物模型、累计量测点 ID）。
  • 提交语义是整表替换（全量覆盖）：不展示新增/变更/删除比对数量；上传后先检查，全部通过才可「确认替换」。第 3 步只展示通过/未通过结论；逐行问题统一下载「错误文件」查看并修改后重传。
请注意：最后确认替换时，系统里的计量关系会整表换成文件里的内容；文件里没有写到的关系会被删掉。上传后会先检查，检查通过才生效。

字段说明 v2.5 产品推断

关联模块：「重算」弹窗 — 入口：历史数据计算规则选第二项后点「重算」

  • 开始日期 / 结束日期：必填，按项目时区。开始不能晚于结束，都不能选未来日。
  • 提交后仅重算当前对象、当前能源、所选日期；按弹窗打开时该对象的当前最新拓扑，不按当时拓扑。
交互说明 v2.5 产品推断

关联模块：「重算」弹窗

  • 打开时带出近 7 天（含今天）。取消或关闭不提交。
  • 确认后关闭弹窗并提示重算成功（原型）。正式产品再补失败保旧与任务列表。
